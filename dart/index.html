    Introducción a Dart¶

    Dart es un lenguaje de programación moderno desarrollado por Google, diseñado para ser rápido, flexible y fácil de aprender. Su objetivo principal es permitir la creación de aplicaciones multiplataforma, tanto para la web como para móviles y servidores, con un único lenguaje y un único código base. Esto hace que Dart sea ideal para desarrolladores que quieren producir aplicaciones eficientes y con buen rendimiento, sin necesidad de mantener diferentes versiones del mismo proyecto.

    Historia y origen de Dart¶

    Dart fue presentado por primera vez en 2011, con la intención de reemplazar a JavaScript en ciertos contextos, ofreciendo un lenguaje más estructurado, tipado y optimizado para aplicaciones modernas.
    A lo largo de los años, Dart ha evolucionado significativamente y, con la aparición de Flutter, se ha consolidado como el lenguaje principal para construir interfaces nativas multiplataforma, combinando velocidad, facilidad de uso y escalabilidad.

    Dart no es solo un lenguaje para móviles; también se puede usar para desarrollo web, servidores y herramientas de línea de comandos. Su sintaxis es sencilla y familiar para programadores de Java, JavaScript o C#, lo que facilita la transición.

    ¿Por qué aprender Dart?¶

    Existen varias razones para aprender Dart hoy en día:

    1. Multiplataforma: Con Flutter, puedes crear apps para Android, iOS, Web, escritorio y más, usando el mismo código.
    2. Productividad: Su sintaxis simple y moderna permite escribir menos código y mantener proyectos más claros.
    3. Rendimiento: Dart compila a código nativo en móviles y a JavaScript en web, logrando aplicaciones rápidas.
    4. Futuro: Dart está en constante evolución y cuenta con el respaldo de Google, además de una comunidad creciente.
    5. Integración con Flutter: Aprender Dart es el primer paso para dominar Flutter y sus widgets, layouts y gestión de estado.

    Qué encontrarás en esta sección¶

    La documentación de Dart en esta web está organizada para que aprendas de lo más básico a lo más avanzado, siguiendo una estructura lógica y progresiva. Cada tema está contenido en ficheros Markdown individuales, de manera que toda la información proviene de texto y se mantiene versionable, editable y mantenible.

    Las secciones principales incluyen:

    • Fundamentos de Dart: Conceptos básicos como variables, operadores, condicionales y bucles.
    • Tipos de Datos: Números, cadenas de texto, booleanos, listas, mapas y conjuntos.
    • Funciones: Declaración, parámetros, funciones anónimas y arrow functions.
    • Colecciones: Uso de List, Map y Set para almacenar y gestionar información.
    • Programación Asíncrona: Trabajar con Future, async y await para operaciones no bloqueantes.
    • Programación Orientada a Objetos (POO): Clases, objetos, constructores, herencia, interfaces y mixins.

    Cada una de estas secciones tendrá ejemplos prácticos que se pueden ejecutar directamente en el navegador utilizando DartPad, lo que permite experimentar con el código en tiempo real. Además, todos los ejemplos están preparados en los ficheros de texto, por lo que siempre se puede actualizar, mejorar o añadir nuevos ejercicios sin modificar la estructura de la web.

    Cómo usar esta documentación¶

    Esta guía ha sido diseñada para que puedas:

    1. Leer los conceptos y explicaciones detalladas.
    2. Ejecutar ejemplos directamente en el navegador usando DartPad embebido.
    3. Modificar y experimentar con los ejemplos sin salir de la web.
    4. Seguir un flujo progresivo: de fundamentos a POO, de Dart básico a Flutter avanzado.

    Al mantener toda la documentación en ficheros de texto, cualquier desarrollador puede contribuir, mejorar ejemplos o añadir nuevas secciones. Esto hace que la web sea colaborativa, clara y sostenible a largo plazo.

    Beneficios de mantener todo en ficheros de texto¶

    • Versionable con Git: Puedes hacer commits, ramas y seguimiento de cambios.
    • Fácil de mantener: Cada fichero Markdown representa una página de la web.
    • Escalable: Se pueden añadir nuevas secciones o ejemplos sin complicaciones.
    • Consistente: Toda la web sigue el mismo estilo y estructura.
    • Interactivo: Cada ejemplo proviene de texto, pero se ejecuta en DartPad, manteniendo la interactividad.

    Próximos pasos¶

    Después de esta introducción, aprenderás los fundamentos de Dart, comenzando por variables, tipos de datos y operadores. Luego pasarás a funciones, colecciones y programación asíncrona, para finalmente dominar POO y prepararte para usar Dart con Flutter, tanto en código como con herramientas visuales drag-and-drop.

    Recuerda: todo lo que verás en esta web proviene de ficheros de texto Markdown, lo que garantiza que la documentación es clara, interactiva y fácil de mantener.
