    Tipos de Datos en Dart¶

    📄 Nota: Esta página forma parte de la guía completa Dart & Flutter. Todo el contenido proviene de ficheros de texto Markdown, lo que garantiza una documentación mantenible, versionable y fácil de colaborar mediante control de versiones (Git).

    ¿Por qué Dart es un lenguaje tipado?¶

    Dart es un lenguaje fuertemente tipado con inferencia de tipos. Esto significa que cada variable tiene un tipo de dato asociado, ya sea declarado explícitamente por el programador o inferido automáticamente por el compilador.

    Ventajas del sistema de tipos de Dart¶

    • Detección temprana de errores: El compilador detecta inconsistencias de tipos antes de ejecutar el código.
    • Mejor autocompletado: Los IDEs (VS Code, Android Studio) ofrecen sugerencias más precisas.
    • Código más legible: El tipo de una variable comunica su intención al lector.
    • Rendimiento optimizado: El compilador puede generar código más eficiente conociendo los tipos de antemano.
    • Seguridad ante null: Con el sistema de sound null safety de Dart, los errores por valores nulos se previenen en tiempo de compilación.

    Tipos Básicos¶

    Dart incluye un conjunto de tipos primitivos que cubren la mayoría de necesidades cotidianas en el desarrollo de aplicaciones.

    int — Números enteros¶

    El tipo int representa números enteros (sin decimales), tanto positivos como negativos.

    void main() {
  int edad = 25;
  int temperatura = -10;
  int millones = 1000000;

  print('Edad: $edad');
  print('Temperatura: $temperatura °C');
  print('Un millón: $millones');

  // Operaciones aritméticas
  int suma = edad + 5;
  int modulo = millones % 3;
  print('En 5 años tendrás: $suma años');
  print('Un millón módulo 3 es: $modulo');
}

    💡 Tip: En Dart, int puede almacenar números muy grandes. En la web, está limitado a 64 bits con signo; en la VM nativa, puede ser arbitrariamente grande.

    double — Números decimales¶

    El tipo double representa números de punto flotante de doble precisión (64 bits).

    void main() {
  double precio = 19.99;
  double pi = 3.14159265;
  double temperatura = -3.5;

  print('Precio: \$$precio');
  print('Pi aproximado: $pi');
  print('Temperatura: $temperatura °C');

  // Conversión entre int y double
  int entero = 7;
  double convertido = entero.toDouble();
  print('Entero convertido a double: $convertido');

  double decimal = 9.8;
  int truncado = decimal.toInt();
  print('Double truncado a int: $truncado');
}

    💡 Tip: Para representar el tipo numérico en general (enteros o decimales), puedes usar la clase abstracta num, de la que heredan int y double.

    String — Cadenas de texto¶

    El tipo String representa secuencias de caracteres Unicode. En Dart, los String son inmutables.

    void main() {
  String nombre = 'Ana García';
  String saludo = "¡Hola, mundo!";
  String multilinea = '''
    Este es un texto
    que ocupa varias
    líneas.
  ''';

  // Interpolación de cadenas
  String ciudad = 'Madrid';
  int anio = 2024;
  print('Bienvenida a $ciudad en el año $anio, $nombre.');

  // Propiedades y métodos útiles
  print('Longitud del nombre: ${nombre.length}');
  print('En mayúsculas: ${nombre.toUpperCase()}');
  print('¿Contiene "García"? ${nombre.contains("García")}');
  print('Reemplazar: ${nombre.replaceAll("Ana", "Carlos")}');

  // Concatenación
  String apellido = 'López';
  String nombreCompleto = nombre + ' ' + apellido;
  print('Nombre completo: $nombreCompleto');
}

    💡 Tip: Usa siempre la interpolación de cadenas ($variable o ${expresion}) en lugar de concatenación con +. Es más legible y eficiente.

    bool — Valores booleanos¶

    El tipo bool solo puede tener dos valores: true (verdadero) o false (falso). Es fundamental para el flujo de control.

    void main() {
  bool esMayorDeEdad = true;
  bool tieneDescuento = false;
  bool estaActivo = true;

  print('¿Es mayor de edad? $esMayorDeEdad');
  print('¿Tiene descuento? $tieneDescuento');

  // Operadores lógicos
  bool puedeComprar = esMayorDeEdad && estaActivo;
  bool necesitaVerificacion = tieneDescuento || !estaActivo;

  print('¿Puede comprar? $puedeComprar');
  print('¿Necesita verificación? $necesitaVerificacion');

  // Comparaciones que devuelven bool
  int edad = 20;
  bool esMenor = edad < 18;
  bool esExacto = edad == 20;

  print('¿Es menor de edad? $esMenor');
  print('¿Tiene exactamente 20 años? $esExacto');
}

    dynamic — Tipo dinámico¶

    El tipo dynamic desactiva la verificación de tipos en tiempo de compilación. La variable puede contener cualquier tipo de valor y cambiar de tipo en tiempo de ejecución.

    void main() {
  dynamic valor = 42;
  print('Valor inicial (int): $valor — Tipo: ${valor.runtimeType}');

  valor = 'Ahora soy un String';
  print('Valor cambiado (String): $valor — Tipo: ${valor.runtimeType}');

  valor = true;
  print('Valor cambiado (bool): $valor — Tipo: ${valor.runtimeType}');

  valor = [1, 2, 3];
  print('Valor cambiado (List): $valor — Tipo: ${valor.runtimeType}');
}

    ⚠️ Advertencia: Usa dynamic con moderación. Al perder la verificación de tipos, también pierdes la seguridad en tiempo de compilación y el soporte del IDE. Prefiere Object? cuando necesites aceptar cualquier valor de forma controlada.

    Tipos de Colecciones¶

    Dart ofrece tres tipos de colecciones integradas que permiten agrupar y organizar múltiples valores de forma eficiente.

    List — Listas (Arrays ordenados)¶

    Una List es una colección ordenada de elementos que permite duplicados. Los índices empiezan en 0.

    void main() {
  // Lista de productos de una tienda
  List<String> productos = ['Manzana', 'Leche', 'Pan', 'Queso', 'Yogur'];

  print('Productos disponibles: $productos');
  print('Total de productos: ${productos.length}');
  print('Primer producto: ${productos[0]}');
  print('Último producto: ${productos.last}');

  // Añadir y eliminar elementos
  productos.add('Mantequilla');
  print('Tras añadir: $productos');

  productos.remove('Pan');
  print('Tras eliminar "Pan": $productos');

  // Iterar la lista
  print('\n--- Lista de compras ---');
  for (String producto in productos) {
    print('• $producto');
  }

  // Lista con tipos mixtos usando dynamic (no recomendado en producción)
  List<dynamic> mixta = [1, 'dos', true, 3.14];
  print('\nLista mixta: $mixta');

  // Lista inmutable
  final List<int> precios = [10, 20, 30, 40];
  print('Precios: $precios');
}

    💡 Tip: Declara siempre el tipo de los elementos: List<String> en lugar de simplemente List. Esto activa la verificación de tipos y mejora el autocompletado.

    Set — Conjuntos (Sin duplicados)¶

    Un Set es una colección no ordenada que no permite elementos duplicados. Es ideal cuando necesitas unicidad.

    void main() {
  // Categorías de una aplicación (sin repeticiones)
  Set<String> categorias = {'Tecnología', 'Deportes', 'Cocina', 'Viajes'};

  print('Categorías: $categorias');
  print('Total de categorías: ${categorias.length}');

  // Intentar añadir un duplicado
  categorias.add('Deportes'); // No se añade
  categorias.add('Música');   // Sí se añade
  print('Tras operaciones: $categorias');

  // Verificar pertenencia (más eficiente que en List)
  print('¿Contiene "Cocina"? ${categorias.contains("Cocina")}');

  // Operaciones de conjuntos
  Set<String> otroSet = {'Tecnología', 'Ciencia', 'Arte'};
  print('\nIntersección: ${categorias.intersection(otroSet)}');
  print('Unión: ${categorias.union(otroSet)}');
  print('Diferencia: ${categorias.difference(otroSet)}');

  // Eliminar duplicados de una lista usando Set
  List<int> conDuplicados = [1, 2, 2, 3, 3, 3, 4];
  Set<int> sinDuplicados = conDuplicados.toSet();
  print('\nLista original: $conDuplicados');
  print('Sin duplicados: $sinDuplicados');
}

    💡 Tip: Usa Set cuando el orden no importa y necesitas evitar duplicados o realizar operaciones matemáticas de conjuntos (unión, intersección, diferencia).

    Map — Mapas (Pares clave-valor)¶

    Un Map almacena datos como pares clave → valor. Las claves son únicas; los valores pueden repetirse.

    void main() {
  // Perfil de usuario como Map
  Map<String, dynamic> usuario = {
    'nombre': 'Carlos Martínez',
    'edad': 32,
    'email': 'carlos@ejemplo.com',
    'activo': true,
  };

  print('Nombre: ${usuario["nombre"]}');
  print('Edad: ${usuario["edad"]}');
  print('Email: ${usuario["email"]}');

  // Añadir y actualizar entradas
  usuario['ciudad'] = 'Barcelona';
  usuario['edad'] = 33; // Actualiza el valor existente
  print('\nUsuario actualizado: $usuario');

  // Verificar existencia de claves y valores
  print('\n¿Tiene "email"? ${usuario.containsKey("email")}');
  print('¿Contiene "Barcelona"? ${usuario.containsValue("Barcelona")}');

  // Iterar sobre el mapa
  print('\n--- Datos del perfil ---');
  usuario.forEach((clave, valor) {
    print('$clave: $valor');
  });

  // Mapa de precios de productos
  Map<String, double> precios = {
    'Manzana': 1.20,
    'Leche': 0.95,
    'Pan': 1.50,
  };

  print('\nTotal de productos: ${precios.length}');
  print('Claves: ${precios.keys.toList()}');
  print('Valores: ${precios.values.toList()}');

  // Eliminar una entrada
  precios.remove('Leche');
  print('Tras eliminar "Leche": $precios');
}

    💡 Tip: Los Map son la estructura clave para trabajar con datos JSON en Flutter. Al deserializar una respuesta de API, obtendrás típicamente un Map<String, dynamic>.

    Resumen Comparativo de Colecciones¶

    Colección Ordenada Duplicados Caso de uso típico
    List ✅ Sí ✅ Sí Listas de elementos, feeds, carritos
    Set ❌ No ❌ No Tags, categorías únicas, filtros
    Map ❌ No* ✅ (valores) Configuración, JSON, perfiles

    *A partir de Dart 2, los Map mantienen el orden de inserción, pero conceptualmente no se consideran colecciones ordenadas por índice.

    Buenas Prácticas con Tipos en Dart¶

    Seguir estas prácticas te ayudará a escribir código Dart más robusto, mantenible y seguro:

    1. Prefiere tipos explícitos sobre var en el ámbito de clase¶

    // ✅ Recomendado en variables de clase
String nombre = 'Ana';
int edad = 25;

// ✅ `var` es aceptable en variables locales cuando el tipo es obvio
var mensaje = 'Hola'; // Dart infiere String
var total = 100;      // Dart infiere int

    2. Evita dynamic salvo que sea estrictamente necesario¶

    // ❌ Evitar
dynamic dato = obtenerDato();

// ✅ Preferir tipado explícito o genéricos
String dato = obtenerDato();
Object? datoFlexible = obtenerDato(); // Más seguro que dynamic

    3. Usa final y const para valores inmutables¶

    // `final`: valor asignado una sola vez en tiempo de ejecución
final String nombreUsuario = obtenerNombre();

// `const`: valor conocido en tiempo de compilación
const double iva = 0.21;
const String appName = 'MiApp';

    4. Especifica siempre los tipos en las colecciones¶

    // ❌ Evitar (tipo inferido como List<dynamic>)
var lista = [];

// ✅ Recomendado
List<String> nombres = [];
Map<String, int> puntuaciones = {};
Set<double> temperaturas = {};

    5. Aprovecha el Null Safety de Dart¶

    // Variable que puede ser null (usa `?`)
String? apellido;

// Variable que nunca puede ser null
String nombre = 'Ana'; // Error de compilación si se asigna null

// Operador de acceso seguro
print(apellido?.length); // No lanza error si es null

// Operador de coalescencia nula
String nombreMostrado = apellido ?? 'Sin apellido';
