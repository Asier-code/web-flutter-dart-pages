    Clases en Dart¶

    📄 Nota: Esta página, como el resto de contenidos de esta guía, proviene de un fichero de texto Markdown. Puedes encontrarla, editarla y versionarla junto al resto de la documentación sin ninguna complicación. La idea es que la guía crezca y se mantenga actualizada de forma sencilla, igual que el código que documenta.

    Si vienes de otros lenguajes orientados a objetos, las clases en Dart te resultarán familiares. Pero aunque la base sea similar, Dart tiene algunos detalles que lo hacen especialmente limpio y práctico.

    Una clase es una plantilla para crear objetos. Agrupa datos (atributos) y comportamientos (métodos) en una sola unidad. Piensa en una clase como el molde de una galleta: defines la forma una vez, y luego puedes crear todas las galletas (objetos) que necesites.

    La clase más simple que puedes escribir¶

    Empecemos con un ejemplo mínimo. Aquí tienes una clase Usuario con dos atributos y un método:

    class Usuario {
  String nombre;
  int edad;

  void saludar() {
    print('Hola, soy $nombre y tengo $edad años');
  }
}

    Para usar esta clase, creas una instancia con new (aunque new es opcional en Dart) y accedes a sus miembros:

    void main() {
  var usuario = Usuario();
  usuario.nombre = 'Carlos';
  usuario.edad = 28;
  usuario.saludar();  // Hola, soy Carlos y tengo 28 años
}

    Pero este código tiene un problema: los atributos nombre y edad pueden estar sin inicializar, y Dart no te dejará pasar si no les das un valor antes de usarlos. Por eso necesitamos constructores.

    Constructores: cómo se crean los objetos¶

    El constructor es el método especial que se ejecuta cuando creas un objeto. Su misión es dejar la instancia en un estado válido desde el principio.

    Constructor básico¶

    La forma más común es usar el constructor con el mismo nombre de la clase:

    class Usuario {
  String nombre;
  int edad;

  // Constructor
  Usuario(String nombre, int edad) {
    this.nombre = nombre;
    this.edad = edad;
  }

  void saludar() {
    print('Hola, soy $nombre y tengo $edad años');
  }
}

// Uso
var usuario = Usuario('Carlos', 28);

    this se refiere a la instancia actual. Es necesario cuando el parámetro tiene el mismo nombre que el atributo.

    Sintaxis azucarada: inicializadores en el constructor¶

    Dart tiene una forma más compacta de escribir lo mismo. Los parámetros se asignan directamente a los atributos sin necesidad de escribir el cuerpo del constructor:

    class Usuario {
  String nombre;
  int edad;

  // Constructor simplificado
  Usuario(this.nombre, this.edad);

  void saludar() {
    print('Hola, soy $nombre y tengo $edad años');
  }
}

    Esta es la forma que verás en la mayoría del código Dart. Es limpia, expresa la intención claramente y evita repetir código.

    Parámetros con nombre y opcionales¶

    Una de las características más útiles de Dart son los parámetros con nombre. En lugar de depender del orden de los argumentos, puedes nombrarlos explícitamente:

    class Usuario {
  String nombre;
  int edad;
  String? email;  // El ? indica que puede ser nulo

  Usuario({
    required this.nombre,
    required this.edad,
    this.email,
  });

  void saludar() {
    print('Hola, soy $nombre');
    if (email != null) {
      print('Mi email es $email');
    }
  }
}

// Uso: el orden no importa
var usuario = Usuario(
  edad: 28,
  nombre: 'Carlos',
  email: 'carlos@ejemplo.com',
);

    required indica que ese parámetro es obligatorio. Los que no tienen required son opcionales. Esta forma hace que el código sea mucho más legible, especialmente cuando las clases tienen muchos atributos.

    Atributos: públicos, privados y getters/setters¶

    En Dart, no hay palabras clave como public o private. En su lugar, la privacidad se indica con un guion bajo (_) al principio del nombre.

    Atributos privados¶

    class CuentaBancaria {
  double _saldo;  // Privado: solo accesible dentro de la clase

  CuentaBancaria(this._saldo);

  void depositar(double cantidad) {
    if (cantidad > 0) {
      _saldo += cantidad;
    }
  }

  double consultarSaldo() {
    return _saldo;
  }
}

    Fuera de la clase, no puedes acceder a _saldo directamente. Solo a través de los métodos públicos que defines.

    Getters y setters¶

    Dart permite definir propiedades calculadas con get y set. Esto te da el control de cómo se accede y modifica un atributo, manteniendo una sintaxis limpia:

    class Rectangulo {
  double ancho;
  double alto;

  Rectangulo(this.ancho, this.alto);

  // Getter: se usa como una propiedad, no como un método
  double get area => ancho * alto;

  // Setter: permite asignar un valor con sintaxis de propiedad
  set area(double valor) {
    // Si cambias el área, ajustamos manteniendo la proporción
    double proporcion = ancho / alto;
    alto = (valor / proporcion).sqrt();
    ancho = alto * proporcion;
  }
}

void main() {
  var rect = Rectangulo(5, 10);
  print(rect.area);  // 50 - se usa como propiedad, no método

  rect.area = 200;
  print(rect.ancho);  // Aprox 10.0
  print(rect.alto);   // Aprox 20.0
}

    Los getters y setters te permiten cambiar la implementación interna sin modificar la interfaz pública de la clase.

    Métodos: comportamientos de la clase¶

    Además de los getters y setters, las clases pueden tener métodos normales. Los métodos pueden recibir parámetros, devolver valores y usar todas las características que ya conoces de las funciones.

    class Calculadora {
  double valorActual = 0;

  void sumar(double cantidad) {
    valorActual += cantidad;
  }

  void restar(double cantidad) {
    valorActual -= cantidad;
  }

  void multiplicar(double cantidad) {
    valorActual *= cantidad;
  }

  double resultado() {
    return valorActual;
  }

  void limpiar() {
    valorActual = 0;
  }
}

    Un detalle importante: si un método no devuelve nada explícitamente, Dart infiere que devuelve void.

    Un ejemplo completo que junta todo¶

    Aquí tienes una clase Producto que muestra atributos, constructor con parámetros con nombre, métodos y un getter:

    class Producto {
  String id;
  String nombre;
  double _precio;  // Privado
  int stock;

  // Constructor con parámetros con nombre
  Producto({
    required this.id,
    required this.nombre,
    required double precio,
    this.stock = 0,  // Valor por defecto
  }) : _precio = precio;  // Inicializador después de :

  // Getter para precio (solo lectura desde fuera)
  double get precio => _precio;

  // Setter con validación
  set precio(double nuevoPrecio) {
    if (nuevoPrecio >= 0) {
      _precio = nuevoPrecio;
    } else {
      print('El precio no puede ser negativo');
    }
  }

  // Método para vender unidades
  bool vender(int cantidad) {
    if (cantidad <= stock) {
      stock -= cantidad;
      print('Vendidos $cantidad unidades de $nombre');
      return true;
    } else {
      print('Stock insuficiente para $nombre');
      return false;
    }
  }

  // Método para reponer stock
  void reponer(int cantidad) {
    if (cantidad > 0) {
      stock += cantidad;
    }
  }

  @override
  String toString() {
    return 'Producto: $nombre | Precio: \$$_precio | Stock: $stock';
  }
}

void main() {
  var producto = Producto(
    id: '001',
    nombre: 'Café molido',
    precio: 8.99,
    stock: 10,
  );

  print(producto);  // Producto: Café molido | Precio: $8.99 | Stock: 10

  producto.vender(3);    // Vendidos 3 unidades de Café molido
  producto.precio = 9.49;
  print(producto.precio); // 9.49

  producto.reponer(5);
  print(producto.stock);  // 12
}

    Lo que es importante llevarse¶

    Las clases en Dart son el pilar de la orientación a objetos en el lenguaje. Lo fundamental que conviene recordar:

    • Usa constructores con this. para asignar parámetros directamente a atributos.
    • Los parámetros con nombre ({this.atributo}) hacen el código más legible, especialmente cuando hay muchos argumentos.
    • La privacidad se indica con _ al principio del nombre. No hay palabras clave public o private.
    • Los getters y setters te permiten controlar el acceso a los atributos con sintaxis de propiedad, no de método.
    • Dart tiene constructores simplificados, inicializadores y valores por defecto que hacen el código más expresivo.

    Cuando estés diseñando tus propias clases, piensa en la interfaz que expones: qué atributos son públicos, qué métodos forman parte de la API y qué detalles quedan ocultos como implementación interna. Un buen diseño de clases es la base para un código mantenible y fácil de entender.
