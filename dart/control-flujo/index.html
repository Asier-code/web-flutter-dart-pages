    Control de flujo en Dart¶

    📄 Nota: Esta página forma parte de la sección de Dart de la guía Dart & Flutter. Como el resto del contenido de esta guía, proviene de ficheros de texto Markdown, lo que permite mantener la documentación organizada, versionada y fácil de actualizar sin depender de ninguna herramienta especial.

    Hasta ahora el código que has visto hace siempre lo mismo: ejecuta una línea, luego la siguiente, luego la siguiente. De arriba a abajo, sin desviarse. Eso está bien para los primeros ejemplos, pero las aplicaciones reales necesitan tomar decisiones. Necesitan hacer cosas distintas según la situación, repetir acciones mientras se cumple alguna condición, o saltar a un camino diferente dependiendo de un valor.

    Para todo eso existe el control de flujo.

    Las estructuras de control de flujo son las herramientas que le dan al programa la capacidad de pensar —o al menos de parecerlo. Son pocas, se aprenden rápido y las usarás en absolutamente todos los proyectos que hagas.

    Tomando decisiones con if y else¶

    La estructura más básica de todas. Le dices al programa: "si se cumple esta condición, haz esto. Si no, haz aquello".

    int temperatura = 22;

if (temperatura > 30) {
  print('Hace mucho calor hoy.');
} else if (temperatura > 20) {
  print('La temperatura es agradable.');
} else {
  print('Hace fresco, coge una chaqueta.');
}

    El programa evalúa las condiciones en orden, de arriba a abajo, y ejecuta el primer bloque cuya condición sea verdadera. Si ninguna lo es, ejecuta el bloque else final, que actúa como red de seguridad.

    Algunas cosas que conviene saber:

    • El else if y el else son opcionales. Puedes tener un if solo si no necesitas alternativa.
    • Puedes encadenar tantos else if como necesites, aunque si hay muchos es señal de que quizás switch encaja mejor.
    • La condición dentro del paréntesis tiene que devolver true o false. Ahí es donde entran los operadores de comparación que viste en los fundamentos.

    Eligiendo entre múltiples opciones con switch¶

    Cuando tienes una variable que puede tomar varios valores distintos y quieres hacer algo diferente para cada uno, switch es más limpio que una cadena larga de else if.

    String diaSemana = 'lunes';

switch (diaSemana) {
  case 'lunes':
    print('Empieza la semana. Ánimo.');
    break;
  case 'viernes':
    print('Ya casi es fin de semana.');
    break;
  case 'sábado':
  case 'domingo':
    print('A descansar.');
    break;
  default:
    print('Un día cualquiera entre semana.');
}

    El programa compara el valor de diaSemana con cada case y ejecuta el bloque que coincida. El break al final de cada caso es importante: le dice al programa que pare ahí y no siga ejecutando el siguiente caso. Si lo olvidas, Dart seguirá ejecutando el código del caso siguiente aunque no coincida.

    El bloque default es el equivalente al else: se ejecuta si ningún case ha coincidido. Es opcional, pero es buena práctica incluirlo para manejar valores inesperados.

    Fíjate en el truco de los días sábado y domingo: al poner dos casos seguidos sin break entre ellos, ambos ejecutan el mismo bloque. Es una forma compacta de agrupar opciones que comparten comportamiento.

    Repitiendo acciones con bucles¶

    Los bucles sirven para ejecutar un bloque de código más de una vez. Sin ellos tendrías que escribir la misma línea repetida, lo cual no escala nada bien. Con ellos, puedes repetir una acción cien veces escribiéndola una sola vez.

    El bucle for¶

    Es el más habitual cuando sabes de antemano cuántas veces quieres repetir algo.

    for (int i = 1; i <= 5; i++) {
  print('Vuelta número $i');
}

    La cabecera del for tiene tres partes separadas por punto y coma:

    • Inicialización: int i = 1 — crea una variable contadora y le da su valor inicial.
    • Condición: i <= 5 — mientras esto sea verdadero, el bucle sigue ejecutándose.
    • Incremento: i++ — lo que ocurre al final de cada vuelta (en este caso, sumar 1 al contador).

    Cuando la condición deja de ser verdadera, el bucle termina y el programa continúa con lo que haya después.

    También existe el for...in, que es más cómodo cuando recorres una lista:

    List<String> frutas = ['manzana', 'pera', 'naranja'];

for (String fruta in frutas) {
  print(fruta);
}

    Mucho más legible que gestionar índices a mano cuando solo necesitas recorrer todos los elementos.

    El bucle while¶

    Se usa cuando no sabes cuántas veces vas a repetir algo, pero sí cuándo quieres parar. El bloque se ejecuta mientras la condición sea verdadera.

    int intentos = 0;

while (intentos < 3) {
  print('Intento número ${intentos + 1}');
  intentos++;
}

    La diferencia clave con for es conceptual: usa for cuando tienes un rango o una colección definida, y usa while cuando la repetición depende de una condición que puede cambiar de formas menos predecibles.

    Una advertencia importante: asegúrate de que la condición eventualmente se vuelve false. Si no, el bucle no termina nunca y el programa se queda bloqueado. Eso se llama bucle infinito y es uno de los errores más comunes al empezar.

    El bucle do-while¶

    Es casi igual que while, con una diferencia importante: la condición se evalúa al final, no al principio. Eso garantiza que el bloque se ejecuta al menos una vez, aunque la condición sea falsa desde el principio.

    int numero = 0;

do {
  print('El número es $numero');
  numero++;
} while (numero < 3);

    Esto es útil en situaciones donde necesitas ejecutar algo una vez y luego decidir si repetir. Un ejemplo clásico: pedirle al usuario que introduzca un dato y repetir hasta que lo haga correctamente. Siempre necesitas preguntar al menos una vez.

    break y continue — controlando el flujo dentro del bucle¶

    A veces necesitas interrumpir un bucle antes de que termine por sí solo, o saltarte una iteración concreta.

    break sale del bucle inmediatamente, aunque la condición todavía sea verdadera:

    for (int i = 0; i < 10; i++) {
  if (i == 5) break;
  print(i); // Imprime 0, 1, 2, 3, 4
}

    continue salta al final de la iteración actual y pasa directamente a la siguiente, sin ejecutar lo que queda del bloque:

    for (int i = 0; i < 6; i++) {
  if (i % 2 == 0) continue;
  print(i); // Imprime 1, 3, 5 — los impares
}

    Úsalos con moderación. Son útiles, pero si abusas de ellos el código se vuelve difícil de seguir. A menudo hay formas más claras de expresar la misma lógica.

    Cuándo usar cada estructura¶

    No hay reglas absolutas, pero sí patrones que con el tiempo se vuelven instintivos:

    • Usa if / else para condiciones basadas en comparaciones o expresiones booleanas.
    • Usa switch cuando compares una variable contra un conjunto de valores concretos y fijos.
    • Usa for cuando sepas cuántas veces repetir, o cuando recorras una colección.
    • Usa while cuando la repetición dependa de una condición que puede cambiar durante la ejecución.
    • Usa do-while cuando necesites garantizar que el bloque se ejecuta al menos una vez.

    Practica antes de seguir¶

    El control de flujo es uno de esos temas que se entienden de verdad solo cuando los usas. Antes de pasar a la siguiente página, prueba a escribir algunos ejemplos sencillos:

    • Un programa que diga si un número es positivo, negativo o cero.
    • Un bucle que imprima los números del 1 al 10 pero se salte los múltiplos de 3.
    • Un switch que, dado el número de un mes, imprima su nombre.

    No tienen que ser perfectos. Solo tienen que funcionar y, sobre todo, tiene que quedar claro en tu cabeza por qué funcionan.
