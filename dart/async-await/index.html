    Programación Asíncrona en Dart¶

    📄 Nota: Esta página forma parte de la guía completa Dart & Flutter. Todo el contenido proviene de ficheros de texto Markdown, lo que garantiza una documentación mantenible, versionable y colaborativa mediante control de versiones (Git).

    ¿Qué es la programación asíncrona?¶

    En un programa síncrono, las instrucciones se ejecutan una tras otra. Si una operación tarda (leer un fichero, consultar una API, esperar 3 segundos), el programa se bloquea hasta que termina, sin poder hacer nada más.

    La programación asíncrona resuelve este problema: permite lanzar una operación lenta y continuar ejecutando otras tareas mientras se espera el resultado. Cuando la operación finaliza, se recoge su resultado y se procesa.

    ¿Por qué es importante en Dart y Flutter?¶

    En aplicaciones móviles y web, casi toda interacción con el mundo exterior es asíncrona:

    • Llamadas a una API REST
    • Lectura y escritura de ficheros
    • Consultas a una base de datos
    • Temporizadores y animaciones
    • Conexiones WebSocket

    Sin asincronía, una app Flutter se congelaría cada vez que hace una petición de red, bloqueando la interfaz y arruinando la experiencia del usuario.

    Cómo implementa Dart la asincronía¶

    Dart utiliza un modelo de bucle de eventos (event loop) de un solo hilo. No usa múltiples hilos para la asincronía general; en su lugar, encola tareas y las ejecuta cuando el hilo principal está libre. Los tres pilares son:

    Concepto Rol
    Future Representa un valor que estará disponible en el futuro
    async Marca una función como asíncrona
    await Pausa la ejecución de la función hasta que el Future se complete

    Future — Un valor en el futuro¶

    Un Future<T> es un objeto que representa el resultado eventual de una operación asíncrona. Puede estar en uno de tres estados:

    • Pendiente: la operación aún no ha terminado.
    • Completado con valor: la operación terminó con éxito y devuelve un valor de tipo T.
    • Completado con error: la operación falló y contiene un error.

    Puedes crear Futures de varias formas:

    import 'dart:async';

void main() {
  print('🚀 Inicio del programa');

  // Future que completa con un valor tras un retraso
  Future<String> saludo = Future.delayed(
    Duration(seconds: 2),
    () => '¡Hola desde el futuro!',
  );

  // Future completado inmediatamente con un valor
  Future<int> numero = Future.value(42);

  // Future completado inmediatamente con un error
  Future<String> fallido = Future.error('Algo salió mal');

  // Encadenamos then/catchError para reaccionar al resultado
  saludo.then((mensaje) => print('📩 Mensaje recibido: $mensaje'));
  numero.then((n) => print('🔢 Número: $n'));
  fallido.catchError((e) => print('❌ Error capturado: $e'));

  print('⏳ Esperando resultados...');
}

    💡 Tip: Fíjate en el orden de los print. El programa imprime "Esperando resultados..." antes de recibir el mensaje del Future.delayed. Esto ilustra perfectamente la naturaleza no bloqueante de la asincronía.

    async y await — La forma moderna de manejar asincronía¶

    La sintaxis async/await permite escribir código asíncrono con una estructura casi idéntica al código síncrono, sin encadenar callbacks ni perder legibilidad.

    Reglas fundamentales¶

    • Una función marcada con async siempre devuelve un Future, aunque no tenga return.
    • Dentro de una función async, puedes usar await para pausar la ejecución hasta que un Future complete.
    • await solo puede usarse dentro de funciones async.

    Funciones async básicas¶

    import 'dart:async';

void main() async {
  print('🚀 Inicio');

  String resultado = await obtenerMensaje();
  print('📩 $resultado');

  int total = await sumar(15, 27);
  print('➕ Suma: $total');

  print('✅ Fin del programa');
}

Future<String> obtenerMensaje() async {
  // Simulamos una operación que tarda 1 segundo (p. ej., llamada a una API)
  await Future.delayed(Duration(seconds: 1));
  return '¡Datos recibidos correctamente!';
}

Future<int> sumar(int a, int b) async {
  await Future.delayed(Duration(milliseconds: 500));
  return a + b;
}

    Simulando llamadas a una API con async/await¶

    En el mundo real, async/await se usa principalmente para consumir servicios externos. El siguiente ejemplo simula una arquitectura de servicio realista:

    import 'dart:async';

// Modelo de datos
class Usuario {
  final int id;
  final String nombre;
  final String email;

  Usuario({required this.id, required this.nombre, required this.email});

  @override
  String toString() => 'Usuario($id, $nombre, $email)';
}

// Servicio simulado (en producción haría una petición HTTP real)
class ApiService {
  Future<Usuario> obtenerUsuario(int id) async {
    print('  📡 Consultando API para usuario $id...');
    await Future.delayed(Duration(seconds: 1)); // simula latencia de red

    if (id <= 0) throw Exception('ID de usuario no válido: $id');

    return Usuario(
      id: id,
      nombre: 'Elena Martínez',
      email: 'elena@ejemplo.com',
    );
  }

  Future<List<String>> obtenerPedidos(int usuarioId) async {
    print('  📡 Consultando pedidos del usuario $usuarioId...');
    await Future.delayed(Duration(milliseconds: 800));
    return ['Pedido #001 — Laptop', 'Pedido #002 — Ratón', 'Pedido #003 — Teclado'];
  }
}

void main() async {
  final api = ApiService();

  print('🚀 Cargando datos del usuario...\n');

  try {
    // Las dos llamadas se hacen secuencialmente
    Usuario usuario = await api.obtenerUsuario(1);
    List<String> pedidos = await api.obtenerPedidos(usuario.id);

    print('✅ Usuario: $usuario');
    print('📦 Pedidos:');
    pedidos.forEach((p) => print('   • $p'));
  } catch (e) {
    print('❌ Error: $e');
  }

  print('\n✅ Carga completada.');
}

    Ejecutar Futures en paralelo con Future.wait¶

    Cuando varias operaciones son independientes entre sí, no tiene sentido ejecutarlas una tras otra. Future.wait las lanza en paralelo y espera a que todas completen.

    import 'dart:async';

Future<String> obtenerNoticias() async {
  await Future.delayed(Duration(seconds: 2));
  return '📰 Últimas noticias cargadas';
}

Future<String> obtenerClima() async {
  await Future.delayed(Duration(seconds: 1));
  return '🌤️  Clima: 22°C, parcialmente nublado';
}

Future<String> obtenerNotificaciones() async {
  await Future.delayed(Duration(milliseconds: 500));
  return '🔔 Tienes 3 notificaciones nuevas';
}

void main() async {
  print('🚀 Cargando dashboard...\n');

  Stopwatch reloj = Stopwatch()..start();

  // ❌ Secuencial: tarda 2 + 1 + 0.5 = 3.5 segundos
  // String n = await obtenerNoticias();
  // String c = await obtenerClima();
  // String notif = await obtenerNotificaciones();

  // ✅ Paralelo: tarda solo lo que tarde el más lento (≈ 2 segundos)
  List<String> resultados = await Future.wait([
    obtenerNoticias(),
    obtenerClima(),
    obtenerNotificaciones(),
  ]);

  reloj.stop();

  resultados.forEach((r) => print(r));
  print('\n⏱️  Tiempo total: ${reloj.elapsedMilliseconds} ms');
}

    💡 Tip: Usa Future.wait siempre que tengas varias operaciones independientes. El ahorro de tiempo puede ser significativo en aplicaciones con múltiples llamadas a APIs.

    Manejo de errores — try/catch con async/await¶

    Los errores en código asíncrono se capturan exactamente igual que en código síncrono: con bloques try/catch/finally.

    import 'dart:async';

Future<String> obtenerDatos(bool simularError) async {
  await Future.delayed(Duration(seconds: 1));
  if (simularError) {
    throw Exception('Error de conexión: servidor no disponible');
  }
  return '✅ Datos obtenidos correctamente';
}

Future<void> cargarConReintentos(int maxIntentos) async {
  int intento = 0;

  while (intento < maxIntentos) {
    intento++;
    try {
      print('🔄 Intento $intento de $maxIntentos...');
      bool fallar = intento < 3; // Falla los dos primeros intentos
      String datos = await obtenerDatos(fallar);
      print(datos);
      return; // Éxito, salimos del bucle
    } catch (e) {
      print('⚠️  Error en intento $intento: $e');
      if (intento < maxIntentos) {
        print('   Reintentando en 1 segundo...');
        await Future.delayed(Duration(seconds: 1));
      }
    } finally {
      print('   (bloque finally siempre se ejecuta)');
    }
  }

  print('❌ No se pudo obtener los datos tras $maxIntentos intentos.');
}

void main() async {
  print('🚀 Iniciando carga con reintentos\n');
  await cargarConReintentos(3);
  print('\n✅ Proceso finalizado');
}

    then / catchError — La alternativa con callbacks¶

    Antes de que async/await se popularizara, la forma estándar de manejar Futures era encadenando métodos .then() y .catchError(). Aún puedes encontrar este patrón en código existente.

    import 'dart:async';

Future<String> consultarServidor() {
  return Future.delayed(
    Duration(seconds: 1),
    () => 'Respuesta del servidor: 200 OK',
  );
}

Future<String> parsearRespuesta(String respuesta) {
  return Future.value('Datos parseados: ${respuesta.split(": ")[1]}');
}

void main() {
  print('🚀 Inicio con then/catchError\n');

  consultarServidor()
    .then((respuesta) {
      print('📡 $respuesta');
      return parsearRespuesta(respuesta);
    })
    .then((datos) {
      print('📦 $datos');
    })
    .catchError((error) {
      print('❌ Error capturado: $error');
    })
    .whenComplete(() {
      print('🏁 Operación completada (whenComplete)');
    });

  print('⏳ El programa continúa mientras espera...');
}

    async/await vs then — ¿Cuál usar?¶

    Criterio async/await .then() / .catchError()
    Legibilidad ✅ Alta (lineal) ⚠️ Media (anidamiento)
    Manejo de errores ✅ try/catch estándar ⚠️ .catchError() separado
    Operaciones encadenadas ✅ Muy claro ⚠️ Puede volverse complejo
    Compatibilidad con callbacks ⚠️ Necesita adaptación ✅ Nativo
    Recomendado para ✅ Uso general Código legado o callbacks simples

    💡 Recomendación: Usa siempre async/await en código nuevo. Es más legible, más fácil de depurar y el estilo oficial recomendado por el equipo de Dart.

    Buenas Prácticas con Código Asíncrono¶

    1. Marca main como async si usas await en él¶

    // ✅ Correcto
void main() async {
  String datos = await cargarDatos();
  print(datos);
}

    2. Captura siempre los errores de los Future¶

    // ❌ Un Future sin captura de error puede causar un crash silencioso
cargarDatos();

// ✅ Captura el error siempre
try {
  String datos = await cargarDatos();
} catch (e) {
  print('Error: $e');
}

    3. Usa Future.wait para operaciones paralelas independientes¶

    // ❌ Secuencial: innecesariamente lento
final usuarios  = await api.getUsuarios();
final productos = await api.getProductos();

// ✅ Paralelo: mucho más eficiente
final resultados = await Future.wait([
  api.getUsuarios(),
  api.getProductos(),
]);

    4. No mezcles await con .then() innecesariamente¶

    // ❌ Mezcla confusa
String datos = await obtenerDatos().then((d) => d.trim());

// ✅ Consistente con async/await
String datos = (await obtenerDatos()).trim();

    5. Usa unawaited para Futures que no necesitas esperar¶

    import 'dart:async';

void main() async {
  // Si no necesitas esperar ni manejar el resultado
  unawaited(registrarEvento('app_inicio'));

  // Tu código continúa sin esperar al Future
  await cargarPantallaInicial();
}

    6. Nombra las funciones asíncronas de forma descriptiva¶

    // ❌ No comunica que es asíncrono ni qué hace
Future<String> datos() async { ... }

// ✅ Nombre claro y descriptivo
Future<List<Producto>> obtenerProductosDestacados() async { ... }
Future<void> guardarPreferenciasUsuario(Map<String, dynamic> prefs) async { ... }
