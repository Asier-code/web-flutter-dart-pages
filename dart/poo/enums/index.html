    Enums en Dart¶

    📄 Nota: Esta página, como el resto de contenidos de esta guía, proviene de un fichero de texto Markdown. Puedes encontrarla, editarla y versionarla junto al resto de la documentación sin ninguna complicación. La idea es que la guía crezca y se mantenga actualizada de forma sencilla, igual que el código que documenta.

    Hay valores que solo pueden ser uno de entre un conjunto limitado de opciones. Los días de la semana, los estados de un pedido, los tipos de usuario, los niveles de log. Para estos casos, los enums son la herramienta perfecta.

    Un enum (enumerado) es un tipo especial que define un conjunto fijo de constantes con nombre. En lugar de andar usando strings sueltos o números mágicos que pueden llevar a errores, los enums te dan un conjunto cerrado de opciones que el compilador entiende y puede validar.

    El problema que resuelven los enums¶

    Sin enums, es fácil terminar con código como este:

    void procesarEstado(String estado) {
  if (estado == 'pendiente') {
    // hacer algo
  } else if (estado == 'enviado') {
    // hacer algo más
  } else if (estado == 'entregado') {
    // hacer otra cosa
  }
}

// En algún lugar de la app
procesarEstado('pendiente');     // funciona
procesarEstado('Pendiente');     // Ups, con mayúscula no funciona
procesarEstado('pendient');      // Un typo y nadie se entera hasta que falla

    Los strings son frágiles. Un error al escribir, una mayúscula de más, y tu lógica se rompe en silencio. Los enums solucionan esto de raíz.

    Definición básica de un enum¶

    La sintaxis es directa. Usas la palabra clave enum seguida del nombre (por convención en PascalCase) y listas los valores separados por comas:

    enum EstadoPedido {
  pendiente,
  confirmado,
  preparando,
  enviado,
  entregado,
  cancelado
}

    Ahora, cuando quieras usar estos valores, no puedes equivocarte:

    void procesarEstado(EstadoPedido estado) {
  if (estado == EstadoPedido.pendiente) {
    print('Esperando confirmación');
  } else if (estado == EstadoPedido.enviado) {
    print('Pedido en camino');
  }
}

// Uso
procesarEstado(EstadoPedido.enviado);  // Claro y seguro

    El compilador sabe exactamente qué valores son válidos. Si intentas pasar algo que no sea un EstadoPedido, simplemente no compila.

    Usando enums con switch¶

    Los enums y switch son una combinación especialmente poderosa. Cuando usas un enum en un switch, Dart te obliga a cubrir todos los casos posibles, o a incluir un default. Esto elimina la posibilidad de olvidarte de manejar un estado:

    String obtenerMensaje(EstadoPedido estado) {
  switch (estado) {
    case EstadoPedido.pendiente:
      return 'Tu pedido está pendiente de confirmación';
    case EstadoPedido.confirmado:
      return 'Pedido confirmado';
    case EstadoPedido.preparando:
      return 'Estamos preparando tu pedido';
    case EstadoPedido.enviado:
      return 'Tu pedido va en camino';
    case EstadoPedido.entregado:
      return 'Pedido entregado. ¡Disfrútalo!';
    case EstadoPedido.cancelado:
      return 'El pedido fue cancelado';
  }
}

    Si más adelante añades un nuevo valor al enum, el compilador te avisará en todos los sitios donde falta manejarlo. Es una red de seguridad muy útil.

    Propiedades útiles de los enums¶

    Todo enum en Dart tiene dos propiedades que te sacan de más de un apuro:

    • .values — devuelve una lista con todos los valores del enum en el orden en que los definiste.
    • .name — devuelve el nombre del valor como string (el nombre que le pusiste, no el índice).
    enum DiaSemana {
  lunes,
  martes,
  miercoles,
  jueves,
  viernes,
  sabado,
  domingo
}

void main() {
  // Recorrer todos los valores
  for (var dia in DiaSemana.values) {
    print(dia.name);  // lunes, martes, miercoles...
  }

  // Convertir de string a enum (útil cuando viene de una API)
  String nombreDia = 'miercoles';
  DiaSemana dia = DiaSemana.values.firstWhere(
    (d) => d.name == nombreDia,
    orElse: () => DiaSemana.lunes,
  );
}

    Enums con valores personalizados (enum mejorados)¶

    Desde Dart 2.17, los enums pueden tener atributos, constructores y métodos. Esto los convierte en algo mucho más potente que una simple lista de constantes.

    enum EstadoHttp {
  ok(200, 'OK'),
  noEncontrado(404, 'Not Found'),
  errorServidor(500, 'Internal Server Error');

  final int codigo;
  final String mensaje;

  const EstadoHttp(this.codigo, this.mensaje);

  bool esExitoso() {
    return codigo >= 200 && codigo < 300;
  }

  @override
  String toString() => '$codigo: $mensaje';
}

void main() {
  var estado = EstadoHttp.ok;
  print(estado.codigo);        // 200
  print(estado.mensaje);       // OK
  print(estado.esExitoso());   // true
  print(estado);               // 200: OK
}

    Este tipo de enums es ideal cuando cada opción tiene datos asociados que necesitas gestionar. Los constructores deben ser const, porque los valores del enum son constantes en tiempo de compilación.

    Un ejemplo práctico en contexto¶

    Imagina que estás construyendo una app con diferentes tipos de usuario. Un enum puede centralizar toda la lógica relacionada con los permisos:

    enum TipoUsuario {
  invitado,
  registrado,
  premium,
  administrador;

  // Getter para saber si puede publicar contenido
  bool get puedePublicar {
    switch (this) {
      case TipoUsuario.invitado:
        return false;
      case TipoUsuario.registrado:
      case TipoUsuario.premium:
      case TipoUsuario.administrador:
        return true;
    }
  }

  // Getter para límite de archivos según el tipo
  int get limiteArchivos {
    switch (this) {
      case TipoUsuario.invitado:
        return 0;
      case TipoUsuario.registrado:
        return 10;
      case TipoUsuario.premium:
        return 100;
      case TipoUsuario.administrador:
        return 9999;
    }
  }

  // Getter para el texto que se muestra en la UI
  String get etiqueta {
    switch (this) {
      case TipoUsuario.invitado:
        return 'Visitante';
      case TipoUsuario.registrado:
        return 'Usuario';
      case TipoUsuario.premium:
        return 'Premium';
      case TipoUsuario.administrador:
        return 'Admin';
    }
  }
}

void main() {
  var usuario = TipoUsuario.premium;

  print(usuario.etiqueta);           // Premium
  print(usuario.puedePublicar);      // true
  print('Límite: ${usuario.limiteArchivos}'); // Límite: 100

  // También puedes usar switch directamente
  switch (usuario) {
    case TipoUsuario.premium:
      print('¡Gracias por ser premium!');
    default:
      print('Mejora a premium para más beneficios');
  }
}

    Lo que es importante llevarse¶

    Los enums son una de esas características que parecen pequeñas pero que tienen un impacto enorme en la claridad y seguridad del código:

    • Reemplazan strings y números mágicos por opciones tipadas y seguras.
    • El compilador te protege cuando usas switch y te olvidas de algún caso.
    • Tienen propiedades útiles como .values y .name para recorrerlos o convertirlos.
    • Pueden llevar datos asociados desde Dart 2.17, lo que los convierte en mini-clases muy prácticas.
    • Hacen el código más legible porque expresan directamente la intención.
