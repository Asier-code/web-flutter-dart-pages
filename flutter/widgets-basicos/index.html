    Widgets Básicos de Flutter¶

    📄 Nota: Esta página forma parte de la guía completa Dart & Flutter. Todo el contenido proviene de ficheros de texto Markdown, lo que nos permite mantener la documentación versionada, colaborativa y fácil de actualizar con Git.

    Si hay una idea que tienes que llevarte clara de esta página es esta: en Flutter, todo es un widget. El texto es un widget. El botón es un widget. El espacio vacío entre dos elementos es un widget. Incluso la propia aplicación es un widget.

    Esto suena raro al principio, especialmente si vienes de Android o iOS donde hay vistas, layouts, actividades y controladores, cada cosa con su nombre propio. Pero una vez que interiorizas el modelo mental de Flutter, el desarrollo se vuelve sorprendentemente consistente: si quieres poner algo en pantalla, hay un widget para eso. Si quieres organizar varios elementos, hay un widget para eso. Si quieres añadir padding, color o un borde, hay un widget para eso.

    En esta página vemos los widgets más fundamentales, los que usarás en prácticamente cualquier pantalla que construyas.

    Text — Mostrar texto¶

    Text es el widget más básico y, probablemente, el que más veces escribirás en tu vida como desarrollador Flutter. Muestra una cadena de texto con la posibilidad de personalizarlo con un TextStyle.

    import 'package:flutter/material.dart';

void main() => runApp(const MaterialApp(home: EjemploText()));

class EjemploText extends StatelessWidget {
  const EjemploText({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Widget Text')),
      body: const Padding(
        padding: EdgeInsets.all(24),
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.start,
          children: [
            // Texto simple
            Text('Texto simple sin estilo'),

            SizedBox(height: 16),

            // Texto con estilo básico
            Text(
              'Título principal',
              style: TextStyle(
                fontSize: 28,
                fontWeight: FontWeight.bold,
                color: Colors.indigo,
              ),
            ),

            SizedBox(height: 8),

            // Texto con múltiples propiedades
            Text(
              'Este es un párrafo de ejemplo con algo más de texto para ver cómo se comporta el ajuste de línea automático.',
              style: TextStyle(
                fontSize: 16,
                height: 1.6,           // interlineado
                color: Colors.black87,
                letterSpacing: 0.3,
              ),
            ),

            SizedBox(height: 16),

            // Texto truncado con ellipsis
            Text(
              'Este texto es muy largo y se va a truncar porque hemos limitado el número de líneas a una sola.',
              maxLines: 1,
              overflow: TextOverflow.ellipsis,
              style: TextStyle(fontSize: 14, color: Colors.grey),
            ),

            SizedBox(height: 16),

            // RichText para texto con estilos mixtos
            Text.rich(
              TextSpan(
                text: 'Flutter ',
                style: TextStyle(fontWeight: FontWeight.bold, fontSize: 18),
                children: [
                  TextSpan(
                    text: 'es ',
                    style: TextStyle(fontWeight: FontWeight.normal, color: Colors.black54),
                  ),
                  TextSpan(
                    text: 'increíble',
                    style: TextStyle(color: Colors.indigo, fontStyle: FontStyle.italic),
                  ),
                ],
              ),
            ),
          ],
        ),
      ),
    );
  }
}

    💡 Tip: En lugar de definir TextStyle a mano cada vez, lo ideal es usar el sistema de tipografía del tema: Theme.of(context).textTheme.titleLarge. Así todos los textos de tu app respetan el diseño global automáticamente.

    Container — El bloque todoterreno¶

    Container es el widget más versátil de Flutter. Es como un div en HTML con superpoderes: puede tener tamaño, color de fondo, bordes, sombras, padding, margin, transformaciones... y puede contener un widget hijo.

    import 'package:flutter/material.dart';

void main() => runApp(const MaterialApp(home: EjemploContainer()));

class EjemploContainer extends StatelessWidget {
  const EjemploContainer({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Widget Container')),
      backgroundColor: Colors.grey[100],
      body: SingleChildScrollView(
        padding: const EdgeInsets.all(24),
        child: Column(
          children: [
            // Container básico con color
            Container(
              width: double.infinity,
              height: 80,
              color: Colors.indigo,
              child: const Center(
                child: Text('Container simple', style: TextStyle(color: Colors.white, fontSize: 18)),
              ),
            ),

            const SizedBox(height: 16),

            // Container con decoración avanzada
            Container(
              width: double.infinity,
              padding: const EdgeInsets.all(20),
              decoration: BoxDecoration(
                gradient: const LinearGradient(
                  colors: [Colors.indigo, Colors.purple],
                  begin: Alignment.topLeft,
                  end: Alignment.bottomRight,
                ),
                borderRadius: BorderRadius.circular(16),
                boxShadow: [
                  BoxShadow(
                    color: Colors.indigo.withOpacity(0.4),
                    blurRadius: 12,
                    offset: const Offset(0, 6),
                  ),
                ],
              ),
              child: const Column(
                crossAxisAlignment: CrossAxisAlignment.start,
                children: [
                  Text('Tarjeta con gradiente', style: TextStyle(color: Colors.white, fontSize: 20, fontWeight: FontWeight.bold)),
                  SizedBox(height: 8),
                  Text('Container con BoxDecoration, gradiente y sombra.', style: TextStyle(color: Colors.white70)),
                ],
              ),
            ),

            const SizedBox(height: 16),

            // Container con borde
            Container(
              width: double.infinity,
              padding: const EdgeInsets.all(16),
              decoration: BoxDecoration(
                color: Colors.white,
                border: Border.all(color: Colors.indigo, width: 2),
                borderRadius: BorderRadius.circular(12),
              ),
              child: const Text('Container con borde redondeado', style: TextStyle(fontSize: 16)),
            ),

            const SizedBox(height: 16),

            // Container como avatar circular
            Container(
              width: 80,
              height: 80,
              decoration: BoxDecoration(
                shape: BoxShape.circle,
                color: Colors.indigo[100],
                border: Border.all(color: Colors.indigo, width: 3),
              ),
              child: const Icon(Icons.person, size: 40, color: Colors.indigo),
            ),
          ],
        ),
      ),
    );
  }
}

    💡 Tip: Si solo necesitas color de fondo sin más decoración, usa color directamente en el Container. Si necesitas borderRadius, sombras o gradiente, entonces usa BoxDecoration — pero no puedes usar color y decoration a la vez; en ese caso el color va dentro de BoxDecoration.

    Row y Column — Organizar en horizontal y vertical¶

    Row y Column son los pilares del layout en Flutter. Row coloca sus hijos en horizontal, Column en vertical. Ambos funcionan exactamente igual, solo cambia el eje principal.

    import 'package:flutter/material.dart';

void main() => runApp(const MaterialApp(home: EjemploRowColumn()));

class EjemploRowColumn extends StatelessWidget {
  const EjemploRowColumn({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Row y Column')),
      body: SingleChildScrollView(
        padding: const EdgeInsets.all(20),
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.start,
          children: [

            // ── ROW básico ──────────────────────────────
            const Text('Row — disposición horizontal:', style: TextStyle(fontWeight: FontWeight.bold)),
            const SizedBox(height: 8),
            Container(
              color: Colors.indigo[50],
              padding: const EdgeInsets.all(12),
              child: const Row(
                mainAxisAlignment: MainAxisAlignment.spaceAround,
                children: [
                  Icon(Icons.home,     size: 36, color: Colors.indigo),
                  Icon(Icons.search,   size: 36, color: Colors.indigo),
                  Icon(Icons.favorite, size: 36, color: Colors.red),
                  Icon(Icons.person,   size: 36, color: Colors.indigo),
                ],
              ),
            ),

            const SizedBox(height: 24),

            // ── COLUMN básica ────────────────────────────
            const Text('Column — disposición vertical:', style: TextStyle(fontWeight: FontWeight.bold)),
            const SizedBox(height: 8),
            Container(
              color: Colors.indigo[50],
              padding: const EdgeInsets.all(12),
              width: double.infinity,
              child: const Column(
                crossAxisAlignment: CrossAxisAlignment.center,
                children: [
                  Icon(Icons.cloud, size: 48, color: Colors.blue),
                  Text('Parcialmente nublado', style: TextStyle(fontSize: 18, fontWeight: FontWeight.bold)),
                  Text('22°C · Valencia', style: TextStyle(color: Colors.grey)),
                ],
              ),
            ),

            const SizedBox(height: 24),

            // ── MainAxisAlignment ────────────────────────
            const Text('mainAxisAlignment — cómo distribuir el espacio:', style: TextStyle(fontWeight: FontWeight.bold)),
            const SizedBox(height: 8),

            _FilaDemo('start',        MainAxisAlignment.start),
            _FilaDemo('center',       MainAxisAlignment.center),
            _FilaDemo('end',          MainAxisAlignment.end),
            _FilaDemo('spaceBetween', MainAxisAlignment.spaceBetween),
            _FilaDemo('spaceAround',  MainAxisAlignment.spaceAround),
            _FilaDemo('spaceEvenly',  MainAxisAlignment.spaceEvenly),

            const SizedBox(height: 24),

            // ── Expanded ─────────────────────────────────
            const Text('Expanded — distribuir espacio disponible:', style: TextStyle(fontWeight: FontWeight.bold)),
            const SizedBox(height: 8),
            Row(
              children: [
                Expanded(
                  flex: 2,
                  child: Container(height: 50, color: Colors.indigo, child: const Center(child: Text('flex: 2', style: TextStyle(color: Colors.white)))),
                ),
                Expanded(
                  flex: 1,
                  child: Container(height: 50, color: Colors.purple, child: const Center(child: Text('flex: 1', style: TextStyle(color: Colors.white)))),
                ),
                Expanded(
                  flex: 1,
                  child: Container(height: 50, color: Colors.pink, child: const Center(child: Text('flex: 1', style: TextStyle(color: Colors.white)))),
                ),
              ],
            ),
          ],
        ),
      ),
    );
  }
}

class _FilaDemo extends StatelessWidget {
  final String etiqueta;
  final MainAxisAlignment alineacion;

  const _FilaDemo(this.etiqueta, this.alineacion);

  @override
  Widget build(BuildContext context) {
    return Padding(
      padding: const EdgeInsets.only(bottom: 6),
      child: Column(
        crossAxisAlignment: CrossAxisAlignment.start,
        children: [
          Text(etiqueta, style: const TextStyle(fontSize: 12, color: Colors.grey)),
          Container(
            color: Colors.indigo[50],
            width: double.infinity,
            child: Row(
              mainAxisAlignment: alineacion,
              children: List.generate(3, (i) => Container(
                width: 36, height: 36,
                margin: const EdgeInsets.all(4),
                color: Colors.indigo[300],
                child: Center(child: Text('${i+1}', style: const TextStyle(color: Colors.white))),
              )),
            ),
          ),
        ],
      ),
    );
  }
}

    💡 Tip: mainAxisAlignment controla el espacio en la dirección principal (horizontal en Row, vertical en Column). crossAxisAlignment controla el alineamiento en la dirección perpendicular. Confundirlos es uno de los errores más comunes al empezar con Flutter.

    Image — Mostrar imágenes¶

    Flutter soporta imágenes desde varias fuentes: red, assets locales, memoria o fichero. El widget Image tiene un constructor diferente para cada caso.

    import 'package:flutter/material.dart';

void main() => runApp(const MaterialApp(home: EjemploImage()));

class EjemploImage extends StatelessWidget {
  const EjemploImage({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Widget Image')),
      body: SingleChildScrollView(
        padding: const EdgeInsets.all(20),
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.start,
          children: [

            // Imagen desde URL
            const Text('Imagen desde red (Image.network):', style: TextStyle(fontWeight: FontWeight.bold)),
            const SizedBox(height: 8),
            ClipRRect(
              borderRadius: BorderRadius.circular(12),
              child: Image.network(
                'https://picsum.photos/seed/flutter/600/300',
                width: double.infinity,
                height: 180,
                fit: BoxFit.cover,
                loadingBuilder: (context, child, progress) {
                  if (progress == null) return child;
                  return Container(
                    height: 180,
                    color: Colors.grey[200],
                    child: const Center(child: CircularProgressIndicator()),
                  );
                },
                errorBuilder: (context, error, stackTrace) {
                  return Container(
                    height: 180,
                    color: Colors.grey[200],
                    child: const Center(child: Icon(Icons.broken_image, size: 48, color: Colors.grey)),
                  );
                },
              ),
            ),

            const SizedBox(height: 24),

            // Imagen circular (avatar)
            const Text('Imagen circular con ClipOval:', style: TextStyle(fontWeight: FontWeight.bold)),
            const SizedBox(height: 8),
            Row(
              mainAxisAlignment: MainAxisAlignment.center,
              children: List.generate(3, (i) =>
                Padding(
                  padding: const EdgeInsets.symmetric(horizontal: 8),
                  child: ClipOval(
                    child: Image.network(
                      'https://picsum.photos/seed/${i + 10}/100/100',
                      width: 70,
                      height: 70,
                      fit: BoxFit.cover,
                    ),
                  ),
                ),
              ),
            ),

            const SizedBox(height: 24),

            // BoxFit options
            const Text('Opciones de BoxFit:', style: TextStyle(fontWeight: FontWeight.bold)),
            const SizedBox(height: 8),
            Row(
              children: [
                _ImagenBoxFit('cover',   BoxFit.cover),
                _ImagenBoxFit('contain', BoxFit.contain),
                _ImagenBoxFit('fill',    BoxFit.fill),
              ],
            ),

            const SizedBox(height: 24),

            // FadeInImage para carga con placeholder
            const Text('FadeInImage (carga suave con placeholder):', style: TextStyle(fontWeight: FontWeight.bold)),
            const SizedBox(height: 8),
            Center(
              child: FadeInImage.assetNetwork(
                placeholder: 'assets/placeholder.png', // necesita el asset en pubspec.yaml
                image: 'https://picsum.photos/seed/fade/400/200',
                width: double.infinity,
                height: 150,
                fit: BoxFit.cover,
                imageErrorBuilder: (context, error, _) =>
                  Container(height: 150, color: Colors.grey[200], child: const Icon(Icons.image, size: 48, color: Colors.grey)),
              ),
            ),
          ],
        ),
      ),
    );
  }
}

class _ImagenBoxFit extends StatelessWidget {
  final String etiqueta;
  final BoxFit fit;
  const _ImagenBoxFit(this.etiqueta, this.fit);

  @override
  Widget build(BuildContext context) {
    return Expanded(
      child: Padding(
        padding: const EdgeInsets.all(4),
        child: Column(
          children: [
            Container(
              height: 70,
              color: Colors.indigo[50],
              child: Image.network(
                'https://picsum.photos/seed/boxfit/200/200',
                fit: fit,
                width: double.infinity,
              ),
            ),
            const SizedBox(height: 4),
            Text(etiqueta, style: const TextStyle(fontSize: 11, color: Colors.grey)),
          ],
        ),
      ),
    );
  }
}

    💡 Tip: Siempre implementa errorBuilder en Image.network. Las imágenes pueden fallar por mil razones (red caída, URL incorrecta, recurso eliminado) y sin un fallback tu app mostrará un widget de error feo al usuario. Con errorBuilder puedes mostrar un icono, un placeholder o un mensaje personalizado.

    ElevatedButton y TextButton — Botones¶

    Los botones son la forma principal de capturar interacciones del usuario. Flutter ofrece varios tipos: ElevatedButton (con relieve), TextButton (plano) y OutlinedButton (con borde). Todos comparten la misma API.

    import 'package:flutter/material.dart';

void main() => runApp(const MaterialApp(home: EjemploBotones()));

class EjemploBotones extends StatefulWidget {
  const EjemploBotones({super.key});

  @override
  State<EjemploBotones> createState() => _EjemploBotonesState();
}

class _EjemploBotonesState extends State<EjemploBotones> {
  String _ultimaAccion = 'Ninguna acción aún';
  int _clics = 0;
  bool _cargando = false;

  void _registrarAccion(String accion) {
    setState(() {
      _ultimaAccion = accion;
      _clics++;
    });
  }

  Future<void> _simularCarga() async {
    setState(() => _cargando = true);
    await Future.delayed(const Duration(seconds: 2));
    setState(() {
      _cargando = false;
      _ultimaAccion = '¡Operación completada!';
      _clics++;
    });
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Tipos de Botones')),
      body: SingleChildScrollView(
        padding: const EdgeInsets.all(24),
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.stretch,
          children: [

            // Estado actual
            Container(
              padding: const EdgeInsets.all(16),
              decoration: BoxDecoration(
                color: Colors.indigo[50],
                borderRadius: BorderRadius.circular(12),
              ),
              child: Column(
                children: [
                  Text('Última acción: $_ultimaAccion', style: const TextStyle(fontSize: 14)),
                  Text('Total de clics: $_clics', style: const TextStyle(fontWeight: FontWeight.bold)),
                ],
              ),
            ),

            const SizedBox(height: 24),
            const Text('ElevatedButton:', style: TextStyle(fontWeight: FontWeight.bold)),
            const SizedBox(height: 8),

            // ElevatedButton básico
            ElevatedButton(
              onPressed: () => _registrarAccion('ElevatedButton pulsado'),
              child: const Text('ElevatedButton básico'),
            ),

            const SizedBox(height: 8),

            // ElevatedButton con icono
            ElevatedButton.icon(
              onPressed: () => _registrarAccion('Guardar pulsado'),
              icon: const Icon(Icons.save),
              label: const Text('Guardar'),
            ),

            const SizedBox(height: 8),

            // ElevatedButton con estilo personalizado
            ElevatedButton(
              onPressed: () => _registrarAccion('Botón personalizado pulsado'),
              style: ElevatedButton.styleFrom(
                backgroundColor: Colors.indigo,
                foregroundColor: Colors.white,
                padding: const EdgeInsets.symmetric(vertical: 16),
                shape: RoundedRectangleBorder(borderRadius: BorderRadius.circular(12)),
              ),
              child: const Text('Botón personalizado', style: TextStyle(fontSize: 16)),
            ),

            const SizedBox(height: 24),
            const Text('TextButton y OutlinedButton:', style: TextStyle(fontWeight: FontWeight.bold)),
            const SizedBox(height: 8),

            Row(
              children: [
                Expanded(
                  child: TextButton(
                    onPressed: () => _registrarAccion('TextButton pulsado'),
                    child: const Text('TextButton'),
                  ),
                ),
                const SizedBox(width: 8),
                Expanded(
                  child: OutlinedButton(
                    onPressed: () => _registrarAccion('OutlinedButton pulsado'),
                    child: const Text('OutlinedButton'),
                  ),
                ),
              ],
            ),

            const SizedBox(height: 24),
            const Text('Botón con estado de carga:', style: TextStyle(fontWeight: FontWeight.bold)),
            const SizedBox(height: 8),

            // Botón desactivado mientras carga
            ElevatedButton(
              onPressed: _cargando ? null : _simularCarga,
              style: ElevatedButton.styleFrom(padding: const EdgeInsets.symmetric(vertical: 14)),
              child: _cargando
                  ? const SizedBox(
                      height: 20, width: 20,
                      child: CircularProgressIndicator(strokeWidth: 2, color: Colors.white),
                    )
                  : const Text('Iniciar operación'),
            ),

            const SizedBox(height: 24),
            const Text('IconButton — botón solo con icono:', style: TextStyle(fontWeight: FontWeight.bold)),
            const SizedBox(height: 8),

            Row(
              mainAxisAlignment: MainAxisAlignment.spaceEvenly,
              children: [
                IconButton(
                  onPressed: () => _registrarAccion('Like ❤️'),
                  icon: const Icon(Icons.favorite_border, color: Colors.red),
                  tooltip: 'Me gusta',
                ),
                IconButton(
                  onPressed: () => _registrarAccion('Compartir 🔗'),
                  icon: const Icon(Icons.share, color: Colors.blue),
                  tooltip: 'Compartir',
                ),
                IconButton(
                  onPressed: () => _registrarAccion('Guardar 🔖'),
                  icon: const Icon(Icons.bookmark_border, color: Colors.orange),
                  tooltip: 'Guardar',
                ),
                IconButton(
                  onPressed: null, // Desactivado
                  icon: const Icon(Icons.delete_outline),
                  tooltip: 'Eliminar (desactivado)',
                ),
              ],
            ),
          ],
        ),
      ),
    );
  }
}

    💡 Tip: Para desactivar un botón, pasa null al parámetro onPressed. Flutter lo muestra automáticamente en un estado visual desactivado. No necesitas ningún flag adicional ni cambiar el estilo manualmente.

    Combinándolo todo — Una tarjeta de perfil real¶

    Los widgets por separado están bien, pero la magia ocurre cuando los combinas. Este ejemplo construye una tarjeta de perfil usando todos los widgets que hemos visto:

    import 'package:flutter/material.dart';

void main() => runApp(const MaterialApp(
  debugShowCheckedModeBanner: false,
  home: Scaffold(
    backgroundColor: Color(0xFFF0F4FF),
    body: Center(child: TarjetaPerfil()),
  ),
));

class TarjetaPerfil extends StatefulWidget {
  const TarjetaPerfil({super.key});

  @override
  State<TarjetaPerfil> createState() => _TarjetaPerfilState();
}

class _TarjetaPerfilState extends State<TarjetaPerfil> {
  bool _siguiendo = false;
  int _seguidores = 1248;

  void _toggleSeguir() {
    setState(() {
      _siguiendo = !_siguiendo;
      _seguidores += _siguiendo ? 1 : -1;
    });
  }

  @override
  Widget build(BuildContext context) {
    return Container(
      width: 320,
      margin: const EdgeInsets.all(16),
      decoration: BoxDecoration(
        color: Colors.white,
        borderRadius: BorderRadius.circular(20),
        boxShadow: [BoxShadow(color: Colors.black.withOpacity(0.1), blurRadius: 20, offset: const Offset(0, 8))],
      ),
      child: Column(
        mainAxisSize: MainAxisSize.min,
        children: [
          // Cabecera con gradiente
          Container(
            height: 100,
            decoration: const BoxDecoration(
              gradient: LinearGradient(colors: [Colors.indigo, Colors.purple]),
              borderRadius: BorderRadius.vertical(top: Radius.circular(20)),
            ),
          ),

          // Avatar encima del gradiente
          Transform.translate(
            offset: const Offset(0, -40),
            child: Column(
              children: [
                Container(
                  padding: const EdgeInsets.all(3),

    Consejos y buenas prácticas¶

    1. Extrae widgets con nombre cuando el árbol crece¶

    Es tentador dejarlo todo en un único build, pero cuando supera las 50 líneas se vuelve difícil de leer. Extraer partes con nombre descriptivo, como _Estadistica en el ejemplo anterior, hace el código infinitamente más mantenible:

    // ❌ Un build con todo mezclado
Column(children: [ /* 80 líneas */ ])

// ✅ Build limpio con widgets extraídos
Column(children: [
  const _CabeceraTarjeta(),
  const _InfoUsuario(),
  _BotonesAccion(onSeguir: _toggleSeguir),
])

    2. Usa const siempre que sea posible¶

    Si un widget no depende de ninguna variable ni estado, márcalo como const. Flutter puede saltarse su reconstrucción en cada setState, lo que mejora el rendimiento:

    // ✅ Flutter no reconstruye estos widgets en cada setState
const Text('Título fijo')
const SizedBox(height: 16)
const Icon(Icons.home)

    3. Prefiere SizedBox sobre Container para espaciado¶

    Si solo necesitas espacio entre widgets, SizedBox es más ligero y expresivo que un Container vacío:

    // ❌ Más verboso de lo necesario
Container(height: 16)

// ✅ Más claro y eficiente
const SizedBox(height: 16)

    4. Padding para márgenes internos, Margin en Container para externos¶

    La distinción entre padding (espacio interior) y margin (espacio exterior) existe en Flutter, pero se maneja diferente que en CSS:

    // Padding interno: el fondo del Container incluye el padding
Container(
  padding: const EdgeInsets.all(16),
  color: Colors.blue,
  child: Text('Con padding interno'),
)

// Margin externo: espacio fuera del Container
Container(
  margin: const EdgeInsets.all(16),
  color: Colors.blue,
  child: Text('Con margen externo'),
)

    5. No anides Column dentro de Column sin necesidad¶

    Anidar columnas y filas innecesariamente complica el árbol y puede causar errores de layout. Si todos los hijos pertenecen al mismo eje, únelos en la misma Column o Row:

    // ❌ Anidamiento innecesario
Column(children: [
  Column(children: [ Text('A'), Text('B') ]),
  Text('C'),
])

// ✅ Una sola Column
Column(children: [ Text('A'), Text('B'), Text('C') ])
