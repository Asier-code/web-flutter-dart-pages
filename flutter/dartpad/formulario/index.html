    Formulario Básico en Flutter¶

    📄 Nota: Esta página forma parte de la sección de ejemplos interactivos de la guía Dart & Flutter. Todo el contenido proviene de ficheros de texto Markdown, lo que permite mantenerlo actualizado y versionado fácilmente.

    Pocas cosas son más habituales en una app móvil que pedir al usuario que escriba algo. Un nombre, un correo electrónico, una contraseña, un mensaje. Los formularios están en todas partes: en el registro, en el login, en el perfil, en el contacto. Saber construirlos bien en Flutter es una de las primeras habilidades prácticas que necesitas.

    Y la buena noticia es que Flutter tiene todo lo necesario para hacerlo de forma sencilla y estructurada.

    Qué hace la app de ejemplo¶

    La app que vamos a ver es deliberadamente simple, pero cubre todo lo que necesitas entender para empezar:

    • Muestra un formulario con dos campos de texto: uno para el nombre y otro para el correo electrónico.
    • El usuario puede escribir libremente en cada campo.
    • Al pulsar el botón de envío, la app valida que los campos no estén vacíos.
    • Si todo es correcto, muestra un mensaje de confirmación con los datos introducidos.
    • Si algo falta, aparece un mensaje de error justo debajo del campo correspondiente.

    Nada de llamadas a servidores, nada de bases de datos. Solo la lógica esencial de un formulario: recoger, validar y mostrar.

    Las piezas que intervienen¶

    Campos de entrada de texto — TextFormField¶

    El widget principal para recoger texto en un formulario es TextFormField. Es similar al TextField básico, pero tiene una ventaja importante: está diseñado para trabajar en equipo con el Form y soporta validación integrada.

    Cada TextFormField puede tener su propia lógica de validación a través de la propiedad validator. Es una función que recibe el texto introducido y devuelve un mensaje de error si algo va mal, o null si todo está bien. Flutter se encarga de mostrar ese mensaje automáticamente debajo del campo.

    El contenedor del formulario — Form¶

    Los campos no viven solos: están envueltos en un widget Form. Este widget actúa como coordinador: cuando le pides que valide, revisa todos los campos que contiene de una sola vez. No tienes que ir campo por campo.

    Para poder hablar con el Form desde el código —para decirle "valida ahora" o "resetéate"— se usa una GlobalKey<FormState>. Piensa en ella como un mando a distancia específico para ese formulario.

    El botón de acción — ElevatedButton¶

    El botón de envío es un ElevatedButton normal. Lo que hace cuando se pulsa es sencillo: le pide al formulario que valide todos sus campos. Si la validación pasa, procesa los datos. Si no, los errores aparecen solos y el usuario sabe qué corregir.

    Validación y actualización de la interfaz¶

    La validación en Flutter no requiere lógica complicada. Cada campo decide sus propias reglas, el formulario las ejecuta todas a la vez, y la interfaz se actualiza automáticamente para mostrar o esconder los mensajes de error.

    Cuando el formulario se envía correctamente, es habitual usar setState para actualizar alguna variable que controle qué se muestra en pantalla: el formulario en sí, un mensaje de éxito, una pantalla de carga...

    El código de ejemplo¶

    import 'package:flutter/material.dart';

void main() => runApp(const MaterialApp(home: AppFormulario()));

class AppFormulario extends StatefulWidget {
  const AppFormulario({super.key});

  @override
  State<AppFormulario> createState() => _AppFormularioState();
}

class _AppFormularioState extends State<AppFormulario> {
  final _formKey = GlobalKey<FormState>();
  final _nombreController = TextEditingController();
  final _emailController = TextEditingController();
  String? _resultado;

  void _enviar() {
    if (_formKey.currentState!.validate()) {
      setState(() {
        _resultado =
            '¡Hola, ${_nombreController.text}! Te contactaremos en ${_emailController.text}.';
      });
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Formulario de contacto'),
        backgroundColor: Colors.teal,
        foregroundColor: Colors.white,
      ),
      body: Padding(
        padding: const EdgeInsets.all(24),
        child: Form(
          key: _formKey,
          child: Column(
            crossAxisAlignment: CrossAxisAlignment.stretch,
            children: [
              TextFormField(
                controller: _nombreController,
                decoration: const InputDecoration(labelText: 'Nombre'),
                validator: (v) =>
                    (v == null || v.isEmpty) ? 'Escribe tu nombre' : null,
              ),
              const SizedBox(height: 16),
              TextFormField(
                controller: _emailController,
                decoration: const InputDecoration(labelText: 'Correo electrónico'),
                keyboardType: TextInputType.emailAddress,
                validator: (v) =>
                    (v == null || !v.contains('@')) ? 'Email no válido' : null,
              ),
              const SizedBox(height: 24),
              ElevatedButton(
                onPressed: _enviar,
                style: ElevatedButton.styleFrom(backgroundColor: Colors.teal),
                child: const Text('Enviar',
                    style: TextStyle(color: Colors.white)),
              ),
              if (_resultado != null) ...[
                const SizedBox(height: 24),
                Text(
                  _resultado!,
                  style: const TextStyle(
                      fontSize: 16, color: Colors.teal),
                  textAlign: TextAlign.center,
                ),
              ],
            ],
          ),
        ),
      ),
    );
  }
}

    Por qué los formularios son fundamentales¶

    Un formulario no es solo un conjunto de cajas donde el usuario escribe. Es el punto de contacto entre la persona y la aplicación: el momento en que el usuario entrega información y la app la recibe, la valida y actúa en consecuencia.

    Casi cualquier flujo importante de una app pasa por un formulario. El registro de una cuenta, el inicio de sesión, la edición de un perfil, el envío de un pedido, la escritura de un comentario. Si esos formularios funcionan mal —si no validan bien, si son difíciles de usar, si dan mensajes de error confusos— el usuario se frustra y abandona.

    Flutter facilita mucho hacer esto bien desde el principio. El sistema de validación integrado en Form y TextFormField es limpio y directo, y los mensajes de error aparecen exactamente donde el usuario necesita verlos.

    Una vez que entiendas este ejemplo, estarás listo para añadir más campos, crear validaciones personalizadas, manejar teclados específicos para cada tipo de dato (números, emails, contraseñas) o conectar el formulario a una API real. Los cimientos son siempre los mismos.
