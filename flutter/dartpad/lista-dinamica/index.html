    Lista Dinámica en Flutter¶

    📄 Nota: Esta página forma parte de la sección de ejemplos interactivos de la guía Dart & Flutter. Todo el contenido proviene de ficheros de texto Markdown, lo que permite mantenerlo actualizado, versionado y colaborativo.

    Si hay algo que aparece en prácticamente cualquier aplicación móvil, es una lista. Una lista de mensajes, de productos, de contactos, de tareas pendientes, de notificaciones... Las apps viven de mostrar colecciones de datos que el usuario puede explorar, filtrar y modificar.

    Este ejemplo muestra cómo construir una lista dinámica en Flutter: una lista que empieza vacía o con unos pocos elementos, a la que el usuario puede añadir nuevos ítems y que se actualiza en pantalla de forma automática. Es sencillo, pero cubre exactamente el patrón que usarás en apps reales.

    Qué hace la app de ejemplo¶

    La app tiene tres comportamientos bien definidos:

    • Muestra una lista de tareas en pantalla, una debajo de la otra, con un pequeño icono y el texto de cada tarea.
    • Permite añadir nuevas tareas a través de un campo de texto y un botón. Cuando el usuario escribe algo y confirma, el elemento nuevo aparece al final de la lista.
    • Se actualiza automáticamente: no hay que recargar nada ni navegar a otra pantalla. En el momento en que se añade la tarea, la lista crece y el nuevo elemento aparece al instante.

    Además, para hacerlo más real, cada tarea se puede marcar como completada pulsando sobre ella, y se puede eliminar deslizándola hacia un lado.

    Las piezas que intervienen¶

    El contenedor visual de la lista — ListView.builder¶

    Flutter tiene varios widgets para mostrar listas, pero ListView.builder es el más habitual en apps reales porque es eficiente: en lugar de construir todos los elementos de golpe, solo construye los que son visibles en pantalla en ese momento. Si la lista tiene mil elementos, Flutter no los renderiza todos al mismo tiempo; los va creando a medida que el usuario hace scroll.

    ListView.builder recibe dos cosas: cuántos elementos tiene la lista (itemCount) y una función que describe cómo se ve cada elemento (itemBuilder). Esa función recibe el índice del elemento que toca construir y devuelve el widget que lo representa.

    Los elementos individuales — ListTile¶

    ListTile es el widget estándar de Flutter para representar un ítem dentro de una lista. Tiene slots predefinidos para un icono a la izquierda, un texto principal, un subtítulo opcional y un widget a la derecha. No es el único widget que puedes usar como elemento de lista, pero es el más cómodo para la mayoría de los casos y respeta automáticamente las guías de Material Design.

    El campo de texto y el botón — TextField y FloatingActionButton¶

    Para que el usuario pueda añadir nuevas tareas necesitas dos cosas: un campo donde escribir y un botón para confirmar. En Flutter, TextField es el widget de entrada de texto y se puede controlar con un TextEditingController, que es un objeto que te permite leer el valor actual del campo y limpiarlo cuando el usuario confirma.

    El botón flotante (FloatingActionButton) activa la acción de añadir: lee el texto del campo, lo añade a la lista y limpia el campo para dejarlo listo para la siguiente tarea.

    La actualización automática — setState y List<String>¶

    La lista de tareas vive como una variable dentro del estado del widget: un simple List<String> que empieza con unos pocos elementos de ejemplo. Cuando el usuario añade una tarea nueva, se llama a setState, que le dice a Flutter que el estado ha cambiado y que debe reconstruir la interfaz con los datos actualizados.

    Este es exactamente el mismo mecanismo que viste en el ejemplo del contador: cambias los datos, llamas a setState, Flutter redibuja. La diferencia es que aquí lo que cambia no es un número sino una lista.

    El código¶

    import 'package:flutter/material.dart';

void main() => runApp(const MaterialApp(
  debugShowCheckedModeBanner: false,
  home: ListaDeTareas(),
));

class ListaDeTareas extends StatefulWidget {
  const ListaDeTareas({super.key});

  @override
  State<ListaDeTareas> createState() => _ListaDeTareasState();
}

class _ListaDeTareasState extends State<ListaDeTareas> {
  // La lista de tareas: el estado principal de la app
  final List<Map<String, dynamic>> _tareas = [
    {'texto': 'Revisar los emails', 'completada': false},
    {'texto': 'Preparar la reunión', 'completada': false},
    {'texto': 'Actualizar la documentación', 'completada': true},
  ];

  // Controlador para leer lo que escribe el usuario en el TextField
  final TextEditingController _controlador = TextEditingController();

  void _agregarTarea() {
    final texto = _controlador.text.trim();
    if (texto.isEmpty) return; // No añadimos tareas vacías

    setState(() {
      _tareas.add({'texto': texto, 'completada': false});
    });

    _controlador.clear(); // Limpiamos el campo de texto
  }

  void _toggleCompletada(int index) {
    setState(() {
      _tareas[index]['completada'] = !_tareas[index]['completada'];
    });
  }

  void _eliminarTarea(int index) {
    setState(() {
      _tareas.removeAt(index);
    });
  }

  @override
  Widget build(BuildContext context) {
    final pendientes = _tareas.where((t) => t['completada'] == false).length;

    return Scaffold(
      appBar: AppBar(
        title: const Text('Mis Tareas'),
        backgroundColor: Colors.indigo,
        foregroundColor: Colors.white,
        bottom: PreferredSize(
          preferredSize: const Size.fromHeight(28),
          child: Padding(
            padding: const EdgeInsets.only(bottom: 8),
            child: Text(
              '$pendientes tarea${pendientes == 1 ? '' : 's'} pendiente${pendientes == 1 ? '' : 's'}',
              style: const TextStyle(color: Colors.white70, fontSize: 13),
            ),
          ),
        ),
      ),
      body: Column(
        children: [
          // Campo para añadir nuevas tareas
          Padding(
            padding: const EdgeInsets.all(16),
            child: Row(
              children: [
                Expanded(
                  child: TextField(
                    controller: _controlador,
                    onSubmitted: (_) => _agregarTarea(),
                    decoration: InputDecoration(
                      hintText: 'Nueva tarea...',
                      prefixIcon: const Icon(Icons.add_task, color: Colors.indigo),
                      border: OutlineInputBorder(borderRadius: BorderRadius.circular(12)),
                      contentPadding: const EdgeInsets.symmetric(horizontal: 16),
                    ),
                  ),
                ),
                const SizedBox(width: 8),
                ElevatedButton(
                  onPressed: _agregarTarea,
                  style: ElevatedButton.styleFrom(
                    backgroundColor: Colors.indigo,
                    foregroundColor: Colors.white,
                    padding: const EdgeInsets.symmetric(horizontal: 16, vertical: 14),
                    shape: RoundedRectangleBorder(borderRadius: BorderRadius.circular(12)),
                  ),
                  child: const Text('Añadir'),
                ),
              ],
            ),
          ),

          // La lista de tareas
          Expanded(
            child: _tareas.isEmpty
                ? const Center(
                    child: Column(
                      mainAxisAlignment: MainAxisAlignment.center,
                      children: [
                        Icon(Icons.check_circle_outline, size: 64, color: Colors.grey),
                        SizedBox(height: 12),
                        Text('¡No hay tareas pendientes!', style: TextStyle(color: Colors.grey, fontSize: 16)),
                      ],
                    ),
                  )
                : ListView.builder(
                    padding: const EdgeInsets.symmetric(horizontal: 16),
                    itemCount: _tareas.length,
                    itemBuilder: (context, index) {
                      final tarea = _tareas[index];
                      final completada = tarea['completada'] as bool;

                      // Dismissible permite eliminar deslizando el elemento
                      return Dismissible(
                        key: Key('$index-${tarea['texto']}'),
                        direction: DismissDirection.endToStart,
                        background: Container(
                          alignment: Alignment.centerRight,
                          padding: const EdgeInsets.only(right: 20),
                          margin: const EdgeInsets.only(bottom: 8),
                          decoration: BoxDecoration(
                            color: Colors.red[400],
                            borderRadius: BorderRadius.circular(12),
                          ),
                          child: const Icon(Icons.delete_outline, color: Colors.white),
                        ),
                        onDismissed: (_) => _eliminarTarea(index),
                        child: Card(
                          margin: const EdgeInsets.only(bottom: 8),
                          shape: RoundedRectangleBorder(borderRadius: BorderRadius.circular(12)),
                          child: ListTile(
                            leading: Icon(
                              completada ? Icons.check_circle : Icons.radio_button_unchecked,
                              color: completada ? Colors.green : Colors.grey,
                            ),
                            title: Text(
                              tarea['texto'] as String,
                              style: TextStyle(
                                decoration: completada ? TextDecoration.lineThrough : null,
                                color: completada ? Colors.grey : Colors.black87,
                              ),
                            ),
                            onTap: () => _toggleCompletada(index),
                          ),
                        ),
                      );
                    },
                  ),
          ),
        ],
      ),
    );
  }
}

    Por qué este patrón está en todas partes¶

    El patrón de lista dinámica es uno de los más utilizados en el desarrollo móvil porque refleja directamente cómo usamos las apps. Los usuarios no interactúan con datos fijos: añaden, modifican, eliminan y reorganizan información constantemente.

    Detrás de la lista de mensajes de WhatsApp, de la bandeja de entrada de Gmail o del carrito de una tienda online hay exactamente el mismo mecanismo: una colección de datos que vive en el estado de la app, un widget que la representa visualmente y un ciclo de actualización que mantiene la interfaz en sincronía con los datos.

    Lo que cambia en apps más complejas es el origen de esos datos (una API, una base de datos local, un stream en tiempo real) y cómo se gestiona el estado a medida que la app crece. Pero el patrón central —datos, vista, actualización— es siempre el mismo.

    Dominar la lista dinámica es dar un paso importante hacia cualquier tipo de app real.
