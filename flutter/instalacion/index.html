    Instalación y Configuración de Flutter¶

    📄 Nota: Esta página forma parte de la guía completa Dart & Flutter. Todo el contenido proviene de ficheros de texto Markdown, lo que nos permite mantener la documentación versionada, colaborativa y fácil de actualizar con Git.

    Antes de escribir una sola línea de Flutter, necesitas tener el entorno preparado. No es el paso más emocionante, lo reconozco, pero si lo haces bien una vez te olvidas de ello para siempre. Esta página te lleva de la mano por cada sistema operativo, paso a paso, sin saltarte nada.

    La instalación de Flutter implica básicamente tres cosas: descargar el SDK, decirle a tu sistema dónde está, y verificar que todo lo que necesita Flutter para funcionar está instalado. Para eso último existe flutter doctor, que es como el mecánico que revisa tu coche antes de salir a la carretera.

    Requisitos previos¶

    Antes de empezar, asegúrate de tener:

    • Conexión a internet estable (la descarga ronda los 600 MB - 1 GB)
    • Al menos 5 GB de espacio libre en disco (más si instalas emuladores Android)
    • 8 GB de RAM como mínimo recomendado (16 GB para trabajar con comodidad)
    • Git instalado en tu sistema

    Instalación en Windows¶

    1. Descargar el SDK de Flutter¶

    Ve a la página oficial de Flutter y descarga el archivo .zip con la última versión estable. En el momento de escribir esto, la versión estable está en la rama stable.

    Una vez descargado, extrae el contenido en una ruta sin espacios ni caracteres especiales. La recomendación oficial es:

    C:\desarrollo\flutter

    ⚠️ Advertencia: Evita rutas como C:\Program Files\flutter o C:\Users\Tu Nombre\flutter (con espacios). Pueden causar problemas difíciles de depurar más adelante.

    2. Añadir Flutter al PATH¶

    Para poder usar el comando flutter desde cualquier terminal, necesitas añadir la carpeta bin del SDK al PATH del sistema:

    1. Abre el menú inicio y busca "Variables de entorno"
    2. Haz clic en "Editar las variables de entorno del sistema"
    3. En la ventana que aparece, haz clic en "Variables de entorno..."
    4. En la sección "Variables del sistema", selecciona la variable Path y haz clic en "Editar"
    5. Haz clic en "Nuevo" y añade la ruta a la carpeta bin de Flutter:
    C:\desarrollo\flutter\bin
    1. Acepta todos los diálogos con "Aceptar"
    2. Abre una terminal nueva (PowerShell o CMD) y verifica que funciona:
    flutter --version

    3. Instalar Git para Windows¶

    Flutter lo necesita internamente. Si no lo tienes, descárgalo desde git-scm.com e instálalo con las opciones por defecto.

    4. Instalar Android Studio¶

    Para compilar para Android necesitas Android Studio y su SDK:

    1. Descarga Android Studio desde developer.android.com/studio
    2. Ejecuta el instalador y sigue los pasos. La instalación estándar incluye el SDK de Android.
    3. Al arrancar por primera vez, completa el asistente de configuración inicial. Asegúrate de que se descarga el Android SDK, el Android SDK Command-line Tools y al menos un emulador de sistema (por ejemplo, Pixel 6 con API 33).

    💡 Tip: Durante la instalación de Android Studio, acepta las licencias de Android cuando te lo pida. Muchos problemas con flutter doctor vienen de licencias sin aceptar. Puedes aceptarlas todas de golpe con: 

    flutter doctor --android-licenses

    5. Verificar la instalación con flutter doctor¶

    Abre una terminal nueva y ejecuta:

    flutter doctor

    Verás una salida similar a esta:

    Doctor summary (to see all details, run flutter doctor -v):
[✓] Flutter (Channel stable, 3.x.x, on Microsoft Windows 11)
[✓] Windows Version (Installed version of Windows is version 10 or higher)
[✓] Android toolchain - develop for Android devices (Android SDK version 34.x.x)
[✓] Chrome - develop for the web
[✓] Visual Studio - develop Windows apps (Visual Studio 2022 17.x.x)
[!] Android Studio (version 2023.x)
    ✗ Unable to find bundled Java version.
[✓] VS Code (version 1.x.x)
[✓] Connected device (3 available)
[✓] Network resources

    El objetivo es que todos los elementos que uses tengan [✓]. Los [!] son advertencias y los [✗] son errores. Cada línea incluye una descripción del problema y en muchos casos la solución directa.

    ⚠️ Error común en Windows: Unable to find bundled Java version en Android Studio. Esto suele resolverse actualizando Android Studio a la última versión o configurando la variable de entorno JAVA_HOME apuntando al JDK incluido en Android Studio: 

    C:\Program Files\Android\Android Studio\jbr

    Instalación en macOS¶

    1. Instalar Flutter con Homebrew (recomendado)¶

    Si tienes Homebrew instalado (y si desarrollas en Mac, deberías tenerlo), la instalación es un solo comando:

    brew install --cask flutter

    Homebrew se encarga de descargar el SDK, colocarlo en el lugar correcto y configurar el PATH automáticamente.

    Verifica que funciona:

    flutter --version

    2. Instalar Flutter manualmente (alternativa)¶

    Si prefieres hacerlo a mano o no usas Homebrew:

    1. Descarga el .zip desde la página oficial
    2. Extrae el contenido en una carpeta de tu elección, por ejemplo ~/desarrollo/flutter
    3. Añade Flutter al PATH editando tu fichero de configuración de shell:

    Para Zsh (el shell por defecto en macOS desde Catalina): 

    echo 'export PATH="$HOME/desarrollo/flutter/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc

    Para Bash: 

    echo 'export PATH="$HOME/desarrollo/flutter/bin:$PATH"' >> ~/.bash_profile
source ~/.bash_profile

    3. Instalar Xcode (para iOS y macOS)¶

    Para poder desarrollar para iOS y macOS necesitas Xcode:

    # Instalar Xcode desde el Mac App Store o con el comando:
xcode-select --install

    Una vez instalado, acepta la licencia:

    sudo xcodebuild -license accept

    Y configura las herramientas de línea de comandos:

    sudo xcode-select --switch /Applications/Xcode.app/Contents/Developer

    4. Instalar CocoaPods¶

    CocoaPods es el gestor de dependencias que usa iOS. Flutter lo necesita para integrar plugins nativos:

    sudo gem install cocoapods

    ⚠️ Nota para macOS con Apple Silicon (M1/M2/M3): Si tienes problemas con CocoaPods en arquitectura ARM, prueba instalarlo con Homebrew en lugar de gem: 

    brew install cocoapods

    5. Instalar Android Studio (para Android)¶

    El proceso es igual que en Windows: descarga desde developer.android.com/studio, instala y completa el asistente inicial. Acepta las licencias:

    flutter doctor --android-licenses

    6. Verificar con flutter doctor¶

    flutter doctor

    En macOS el resultado ideal incluye tanto Android como iOS:

    [✓] Flutter (Channel stable, 3.x.x, on macOS 14.x)
[✓] Xcode - develop for iOS and macOS (Xcode 15.x)
[✓] Chrome - develop for the web
[✓] Android toolchain - develop for Android devices
[✓] Android Studio (version 2023.x)
[✓] VS Code (version 1.x.x)
[✓] Connected device (4 available)

    💡 Tip: En macOS puedes desarrollar para iOS directamente en el simulador de Xcode sin necesitar un dispositivo físico. Para Android sí necesitarás un emulador o un dispositivo con depuración USB activada.

    Instalación en Linux¶

    1. Instalar dependencias del sistema¶

    Antes de instalar Flutter, asegúrate de tener las herramientas necesarias:

    # Ubuntu / Debian
sudo apt-get update
sudo apt-get install -y curl git unzip xz-utils zip libglu1-mesa clang cmake \
  ninja-build pkg-config libgtk-3-dev liblzma-dev libstdc++-12-dev

# Fedora / RHEL
sudo dnf install -y curl git unzip which clang cmake ninja-build \
  gtk3-devel pkgconf-pkg-config

    2. Instalar Flutter con snap (Ubuntu)¶

    En Ubuntu y distribuciones basadas en él, la forma más sencilla es con snap:

    sudo snap install flutter --classic

    Verifica la instalación:

    flutter --version

    3. Instalación manual (cualquier distribución)¶

    1. Descarga el tarball desde la página oficial
    2. Extrae en tu carpeta de preferencia:
    mkdir -p ~/desarrollo
cd ~/desarrollo
tar xf ~/Descargas/flutter_linux_*.tar.xz
    1. Añade Flutter al PATH:
    echo 'export PATH="$HOME/desarrollo/flutter/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc

    Si usas Zsh: 

    echo 'export PATH="$HOME/desarrollo/flutter/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc

    4. Instalar Android Studio en Linux¶

    # Con snap
sudo snap install android-studio --classic

# O descargando el tarball desde developer.android.com/studio

    Tras instalarlo, lanza Android Studio y completa el asistente de configuración para descargar el SDK de Android.

    Acepta las licencias desde terminal: 

    flutter doctor --android-licenses

    5. Verificar con flutter doctor¶

    flutter doctor

    ⚠️ Error común en Linux: clang: error: linker command failed. Asegúrate de tener clang y cmake instalados (el paso de dependencias del sistema lo cubre). Si el error persiste, instala también build-essential: 

    sudo apt-get install build-essential

    Configurar el editor — VS Code¶

    Puedes usar Android Studio como IDE completo, pero muchos desarrolladores prefieren VS Code por su ligereza. La configuración es igual en los tres sistemas operativos:

    1. Descarga e instala VS Code
    2. Abre VS Code y ve a la pestaña de Extensiones (Ctrl+Shift+X / Cmd+Shift+X)
    3. Busca e instala las dos extensiones oficiales:
    4. Flutter (publicada por Dart Code) — incluye la extensión de Dart automáticamente
    5. Dart (si no se instaló con Flutter)

    Con estas extensiones tendrás: - Autocompletado de widgets y propiedades - Atajos para crear StatelessWidget y StatefulWidget rápidamente - Hot Reload y Hot Restart desde la barra de herramientas - Depurador visual integrado - Análisis de código en tiempo real

    Crear y ejecutar tu primer proyecto desde VS Code¶

    # Desde la terminal integrada de VS Code
flutter create mi_primera_app
cd mi_primera_app
flutter run

    O usando la paleta de comandos: Ctrl+Shift+P → Flutter: New Project.

    Errores comunes y cómo resolverlos¶

    Error Causa probable Solución
    flutter: command not found Flutter no está en el PATH Verifica que añadiste la ruta bin al PATH y abre una terminal nueva
    Android license status unknown Licencias sin aceptar flutter doctor --android-licenses
    Unable to locate Android SDK SDK no instalado o ruta incorrecta Reinstala Android Studio y completa el asistente
    CocoaPods not installed (macOS) CocoaPods falta sudo gem install cocoapods o brew install cocoapods
    Xcode installation is incomplete Xcode sin herramientas CLI xcode-select --install
    JAVA_HOME not set Variable de entorno faltante Configura JAVA_HOME apuntando al JDK de Android Studio

    Consejos y buenas prácticas¶

    Mantén Flutter actualizado¶

    Flutter evoluciona rápido. Para actualizar a la última versión estable:

    flutter upgrade

    Para ver qué versión tienes y qué canales existen:

    flutter --version
flutter channel       # muestra los canales disponibles (stable, beta, master)
flutter channel stable  # cambia al canal estable

    Usa flutter doctor -v para diagnóstico detallado¶

    La versión con -v (verbose) da mucho más detalle sobre cada componente:

    flutter doctor -v

    Es especialmente útil cuando hay un [!] y quieres entender exactamente qué falla.

    Crea un emulador desde la terminal¶

    No necesitas abrir Android Studio para crear o lanzar un emulador:

    flutter emulators            # lista los emuladores disponibles
flutter emulators --launch <nombre_emulador>   # lanza uno
flutter run                  # despliega la app en el emulador activo

    Verifica los dispositivos conectados¶

    flutter devices   # lista todos los dispositivos y emuladores disponibles

    Configura un dispositivo físico Android¶

    1. En tu Android, ve a Ajustes → Acerca del teléfono
    2. Pulsa "Número de compilación" 7 veces hasta activar las opciones de desarrollador
    3. Ve a Ajustes → Opciones de desarrollador y activa "Depuración USB"
    4. Conecta el dispositivo con un cable USB y acepta la solicitud de depuración en el dispositivo
    5. Verifica con flutter devices que aparece en la lista
